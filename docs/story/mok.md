# 목 노인 대사 풀

기획서 2장(거점 인물)과 21장(환혼과 윤회)을 따른다. 목 노인은 침방에서 쓰러진 혼을 회혼침으로 붙잡아 그날 밤 숨진 제자의 몸에 옮겨 심는다. 정체는 단목현이 혈해마공을 완성하던 날 떨어져 나간 의원의 마음이지만, 대사에서는 끝까지 말하지 않고 암시만 한다.

## 쓰는 법

- 객잔으로 돌아올 때마다 많아야 두 마디. 조건이 겹치면 첫 환혼, 땅의 주인, 봉인석, 처음 오른 경지, 좌화, 생 횟수 순으로 고르고 밀린 줄은 다음에 돌아올 때 한다.
- 문파 첫 환생 줄은 침방에서 그 문파 후보를 처음 고를 때 나온다. 첫 환혼 때도 고른 문파의 줄이 나온다.
- 생 횟수는 서장(진소운 제 몸)을 빼고 센다. 'N번째'는 환생한 몸으로 산 N번째 생이 끝나고 돌아왔을 때다.
- 처음 오른 경지, 봉인석, 땅의 주인은 계정 전체로 한 번씩만 한다.

## 말투

- 반말이고 짧다. 길어야 두 문장.
- 삼백 년 전 일을 옆에서 본 사람처럼 말한다. "그날", "그 골짜기" 하고 가리키기만 한다.
- 맥, 침, 열, 약 같은 의원의 말이 섞인다. 혈마는 이름 대신 "그 사람"이라고만 부른다.

## 첫 환혼

| 조건 | 대사 |
| --- | --- |
| 서장이 끝나고 침방이 처음 열릴 때 | 네 몸은 다했다. 혼까지 보낼 수는 없지. |
| 환생 후보 셋을 처음 보여 줄 때 | 오늘 밤 숨진 아이들이다. 하나를 골라 그 몸으로 다시 걸어라. |
| 처음 고른 뒤, 그 몸에 침을 놓을 때 | 따끔할 게다. 남의 몸은 처음엔 다 그렇다. |
| 첫 환생 직전 | 이 아이는 강시로 일어나지 않겠구나. 그거면 됐다. |

## 생 횟수

| 조건 | 대사 |
| --- | --- |
| 1번째 생이 끝나고 | 첫 몸은 다들 낯설어한다. 남의 신을 신고 뛴 셈이니. |
| 3번째 | 세 번째다. 맥이 처음보다 고르다. |
| 10번째 | 열 번째다. 몸은 바뀌어도 혼에는 굳은살이 박인다. |
| 30번째 | 서른 번이다. 죽어도 돌아온다는 게 얼마나 달콤한지, 나는 안다. |
| 100번째 | 백 번이면 죽음이 무섭지 않겠지. 나는 그게 제일 무섭다. |

## 처음 오른 경지

| 조건 | 대사 |
| --- | --- |
| 이류 | 이류라. 이제 빗방울이 살갗 앞에서 비켜 갈 게다. |
| 일류 | 일류면 사람들이 우러러본다. 그 눈빛에 맛 들이지 마라. |
| 절정 | 절정이다. 이제 땅의 주인들도 너를 알아본다. |
| 초절정 | 산이 손바닥만 해 보였을 게다. 그 사람도 그 무렵부터 사람을 쉽게 썼지. |
| 화경 | 화경이라. 삼백 년 전 그 골짜기에서도 그런 금빛을 봤다. |
| 현경(처음 오른 생에 봉인석이 일곱이 안 될 때) | 현경에 올라도 돌이 모자랐지. 그 그림자가 쫓아온 건 너를 탐내서다. |
| 현경(봉인석 일곱을 지니고 처음 현경에 선 생) | 골짜기 문이 열렸다. 그 안에서 누가 기다리는지는 가 보면 안다. |

## 봉인석 개수

| 조건 | 대사 |
| --- | --- |
| 1개 | 벌써 하나가 돌아왔구나. |
| 2개 | 둘이다. 그날은 일곱을 다 놓는 데 사흘이 걸렸지. |
| 3개 | 셋이다. 돌을 맡았던 이들 얼굴이 하나씩 떠오른다. |
| 4개 | 넷이다. 넷째 돌을 놓을 무렵이었지, 처음 사람이 쓰러진 게. |
| 5개 | 돌을 쥐면 손이 차지? 그 사람 손은 늘 따뜻했는데. |
| 6개 | 하나 남았다고 서두르지 마라. 조급하면 맥이 먼저 안다. |
| 7개 | 일곱이 다 모였다. 이번에는 가두고 끝날지, 나도 모르겠다. |

1개 줄은 기획서 19장 C(1장 컷신) 컷 7의 대사를 그대로 옮겼다.

## 문파 첫 환생

| 조건 | 대사 |
| --- | --- |
| 소림 | 소림 아이다. 염불은 몰라도 된다, 주먹은 몸이 기억한다. |
| 개방 | 배곯던 몸이다. 먹은 게 살로 잘 붙는다. |
| 남궁 | 남궁의 피다. 기혈이 넉넉할 땐 검이 하늘을 찌르지만, 바닥나면 금방 꺾인다. |
| 당가 | 당가 몸은 독을 타지 않는다. 독과 약이 한 뿌리라는 걸 잊지 마라. |
| 수로채 | 물에서 자란 몸이다. 뭍에서도 발이 가볍지. |
| 무당 | 무당 몸은 음양이 고르다. 기울거든 숨부터 골라라. |
| 화산 | 화산이라. 검을 쥐어 보면 안다, 처음 쥐는 검이 아니라는 걸. |
| 곤륜 | 곤륜 아이다. 부적 쓰는 손은 차가워서 강시가 싫어하지. |
| 마교 | 마교 몸이다. 이 무공은 피를 먹고, 배가 불러도 멈추지 않는다. |

## 좌화로 끝낸 생

| 조건 | 대사 |
| --- | --- |
| 처음 좌화로 생을 닫았을 때 | 스스로 앉았구나. 버틸 까닭이 없을 때 앉을 줄 아는 것도 공부다. |
| 두 번째 좌화부터 무작위 | 앉아서 간 얼굴은 편하다. 열에 들떠 간 얼굴은 오래 남지. |
| 혈마의 그림자에 쫓기다 좌화 | 그림자한테 잡히기 전에 앉았다니, 잘했다. |

## 땅의 주인을 처음 쓰러뜨린 뒤

| 조건 | 대사 |
| --- | --- |
| 혈나한 원각 | 안에서 열렸다고 하더냐. 문은 늘 안에서 먼저 열린다. |
| 독후 당소혜 | 독으로 독을 막으려 했구나. 몰라서가 아니라 급해서였을 게다. |
| 혈귀 마천패 | 지킨 값을 받고 싶었던 게지. 삼백 년이면 누구라도 지친다. |
| 혈허진인 | 의원이었다는 말을 들었구나. 그래, 침 놓는 솜씨가 좋았지. |
| 낙매검선의 검혼 | 그 검객은 끝까지 베지 않았다. 고칠 수 있다고 믿은 건 그 하나뿐이었다. |
| 빙혈 설무향 | 그 산마을은 기침 소리로 가득했다. 아이들 이마가 불덩이 같았다. |
| 혈영회주 혁련휘 | 아무도 잃지 않겠다는 말, 삼백 년 전에도 들었다. |

어느 순서로 쓰러뜨려도 말이 되게 썼다. 혁련휘 줄은 컷신(`boss_cuts.md`)에서 혁련휘가 남기는 "아무도 잃지 않는 세상"을 받는다.

## 아직 정하지 않은 것

- 혈월 천하(회귀)에서 봉인석을 다시 모을 때의 줄, 진엔딩 조건인 '목 노인의 대화를 끝까지 보기' 줄기는 이 풀에 없다.
- 처음 오른 경지는 이류부터 현경까지 여섯이다. 현경을 봉인석 수에 따라 두 줄로 나눠 일곱 줄을 채웠다.
