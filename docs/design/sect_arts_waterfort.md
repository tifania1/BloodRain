# 문파 무공 늘리기 — 수로채 다섯 설계안 (WS-04 앞당김)

2026-11-26 03시 밤 개발 세션이 씀. 소림(`sect_arts.md`, #59)·개방(#65)·남궁(#66)·당가(`sect_arts_tang.md`, #71)와 같은 틀. **사람 확인 대기**(decisions #72). 소림 설계안의 공통 규칙(6단은 대표 무공에만, 자기 문파 무공 뽑기 무게 ×1.5, 다른 몸은 땅의 주인 해금)이 바뀌면 이 문서도 같이 바뀐다. 숫자는 전부 **추천값**이다.

## 다른 문파와 다른 점
- 수로채 시너지 구성원에 공격 무공이 둘이다(`synergies.json` waterfort: 쇄겸술·이화창 + 수룡심법·천리안). 그래서 **대표 쇄겸술 + 이화창 + 새 셋**.
- `sect_arts.md` 초안 넷 가운데 하나를 뺐고 하나는 이름을 바꿨다.
  - '철쇄횡강(사슬로 줄지은 적 끌기)'은 대표 쇄겸술(`pull_chain`, 사슬로 끌어옴)과 겹친다.
  - '수룡편'은 수로채 심법 '수룡심법'과 이름이 겹쳐 '회류편'으로 바꿨다.
- 새 심법은 만들지 않는다. 수룡심법에 둘, 천리안에 하나. 이화창 짝은 지금처럼 운룡보(무당 쪽) 그대로.

## 새 셋 하나씩

### 분수도 — 앞으로 퍼지는 물결 (`wave_slash`, 새 방식)
- 판정: 바라보는 쪽 100° 부채꼴 띠가 0.4초 동안 몸에서 4m 까지 퍼져 나간다. 띠(두께 0.6m)가 지나는 적에게 한 번, 넉백 4(밀려나는 쪽은 몸에서 바깥). Lv5 0.2초 뒤 둘째 물결(피해 ×0.7).
- 견준 것: 삼재검법(`front_arc`, 12→37 / 1.2초, 2.2m)보다 멀리 닿고 느리다. 음공(`ring_wave`, 10→28 / 2.5초, 둘레 5m)의 '앞쪽만, 더 세게' 짝. Lv8 한 적 초당 ≈ (40 + 28) / 1.7 ≈ 40 은 앞에 몰린 적일 때만.
- 수룡심법의 탄속 +10%/Lv 가 물결 퍼지는 빠르기에 붙는다(띠가 빨리 닿음).
- 다섯 단계: 초식 마른 먹 물결 줄 → 경력 띠 끝 먹 튐 → 기 문파 상징색(#1F7A64) 담채 물빛 → 기인 둘째 물결이 흰 물보라 앞머리 → 강기 물결이 강물 갈라지듯 양쪽으로 벽을 세움(그림만, 판정은 같음).

### 어망술 — 빽빽한 자리에 그물 (`net_throw`, 새 방식)
- 판정: 6m 안에서 적이 가장 많이 모인 자리(반경 2.0m 원 안 적 수가 가장 많은 곳 — 벽력탄 `seekRange` 고르기와 같은 셈을 쓰되 '가장 많은 곳')에 0.35초 날아가 그물이 펼쳐진다. 안의 일반 적은 1.5초 묶임(제자리에 멈춤), 정예는 50% 느려짐, 땅의 주인은 안 걸림. 묶인 동안 0.5초마다 피해. Lv5 그물 둘(둘째는 그다음으로 많은 곳).
- 견준 것: 공격보다 묶기 쪽. Lv8 한 그물 초당 ≈ 10 × 2 × 1.5 / 4.0 ≈ 7.5(적마다), 반경 2.6m 안 열 마리면 75. 벽력탄(25→60 / 3.0초) 무리 처리와 비슷하되 한 번에 터지지 않고 붙잡아 둔다. 다른 무공(분수도·회류편)이 묶인 무리를 때리게 하는 짝.
- 천리안(치명 +4%/Lv)은 그물 피해에도 붙는다. '눈이 밝아 빽빽한 곳을 본다'는 결로 짝을 맞췄다.
- 묶인 적은 '느려짐' 위에 '멈춤'이라 쇄겸술 느려짐과 겹치면 멈춤이 이긴다.
- 다섯 단계: 초식 먹 그물코 → 경력 그물 가장자리 추가 먹점 → 기 물빛 담채 → 기인 걷힐 때 그물이 물방울로 흩어짐 → 강기 그물코마다 작은 금빛 매듭.

### 회류편 — 긴 채찍 쓸기 (`whip_sweep`, 새 방식)
- 판정: 길이 5.5m 채찍이 바라보는 쪽 150° 를 0.3초에 한쪽에서 반대쪽으로 쓴다. 쿨다운마다 쓰는 방향이 번갈아 바뀐다(왼→오, 오→왼). 채찍 끝 1m 안은 피해 ×1.5. 넉백 2. Lv4 끝에서 되돌아 한 번 더(피해 절반). Lv7 길이 6.5m.
- 견준 것: 취선봉(`random_arc`, 18→45 / 1.8초, 3m)보다 길고 한 번은 약하다. 끝에 닿게 거리를 두는 '물가 싸움'. Lv8 끝 맞은 적 초당 ≈ (34 × 1.5 + 17) / 1.5 ≈ 45, 몸 가까이는 ≈ 34.
- 다섯 단계: 초식 가는 먹 곡선 → 경력 끝에서 먹 튐 → 기 지나간 자리 물빛 담채 → 기인 끝이 터질 때 물보라 → 강기 채찍이 물줄기 용 그림자로.

## 절기와 6단
- 절기(이름과 모양만):
  - 단강일도: 물결이 4m 끝에서 양옆으로 갈라져 몸 쪽으로 한 번 더 돌아온다(갇힌 적은 두 번 맞음).
  - 천라지망: 그물이 하나로 커져(반경 ×2) 묶인 적을 그물 한가운데로 끌어모은 뒤 걷힐 때 한 번 조인다(피해 ×3).
  - 노도회류: 채찍이 한 바퀴(360°) 돌고, 끝이 지나간 자리에 1초 물보라 띠.
- 6단은 쇄겸술에만(`sinbyeong.md` 분수합일). 수로채 병기 분수겸(`gear.json`) 등급 보너스는 다섯 무공 모두에.
- 수로채 고유 능력(움직이는 동안 회피 +15%, 물 무시 `traitEffect`)은 무공에 따로 붙는 것이 없다. 장강 물길에서 수로채 몸만 물속을 그대로 걸어 분수도·회류편 거리를 맞추기 쉽다.

## 레벨업 풀에 들어오는 규칙
- 수로채 몸: 새 셋이 처음부터.
- 다른 몸: 계정에서 마천패(장강 땅의 주인)를 처음 잡은 뒤부터(`unlock: "boss:janggang"` — 쇄겸술·수로채 몸 해금과 같은 토큰).
- 수로채 시너지 구성원 넷 → 일곱. 단계 문턱 그대로.

## 수로채 한 생 밸런스에 끼치는 것 (데이터로 옮길 때 잴 것)
- 수로채 몸 30판: 경지 시각이 지금과 ±10% 안인지, 마천패 처치 시각(기획서 6장 목표) 안인지.
- 어망술의 '멈춤'이 쇄겸술 느려짐·태극검 같은 둘레 무공과 겹쳐 '적이 아예 못 오는' 빌드를 만들지. 받는 접촉 피해가 지금 가장 단단한 빌드보다 15% 넘게 줄면 묶음 1.5초 → 1.0초.
- 어망술 고르기(가장 많은 곳)는 적이 600마리일 때 매번 다 세면 무겁다. Core 에서는 격자(2m 칸)에 센 수로 고른다 — 데이터로 옮길 때 `EnemySim` 격자를 쓰는지 본다.

2. 짝 심법: 새 심법 없이 수룡심법에 둘, 천리안에 하나. 추천: 이대로.
3. 다른 몸은 마천패 첫 처치로 열림. 추천: 이대로.
