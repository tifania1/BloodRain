# 합격 절기 셋과 단전 한도 판단 (GU-08, 2026-11-24 밤 개발 세션)

roguelike_benchmark 안 ⑤(합격 절기를 얼리 액세스로 당기기)와 안 ⑥ 뒷부분(단전 한도). 사람은 2026-11-13 '추천 순서대로 전부'로 방향을 정했다. 기획서 9장 '합격 절기(출시 후 업데이트)'에는 짝과 이름만 있고 효과·숫자가 없어 아래는 **추천값**이다. 사람 확인 대기: decisions #64.

## 1. 합격 절기 셋

### 공통 규칙(기획서 9장 그대로 + 추천)
- 두 절기를 모두 가진 채 혈정 보갑을 열면 하나로 합쳐진다(9장). 무공 칸 하나가 빈다 — 화경 구간에 그 칸으로 새 무공을 받아 다시 레벨업이 살게 하는 것이 이 안의 까닭이다.
- 짝 심법 둘은 그대로 남는다(심법 칸은 비지 않음).
- 화력(추천): 합친 절기 한 판 피해가 두 절기 합의 **1.3배**. 칸 하나를 내준 값으로, 빈 칸에 받은 새 무공이 Lv8 이 되기 전까지 손해가 없게.
- 해금: 10장 해금 표의 '모든 절기 1회씩 완성 → 합격 절기'는 얼리 액세스에서 너무 멀다(16 절기). **추천: 그 짝의 두 절기를 각각 한 번이라도 깨운 혼이면 연다.** 표 줄을 이렇게 바꾼다.
- 6단(신병합일)과는 따로다. 6단은 대표 무공 한 자루에, 합격은 두 절기를 하나로. 둘 다 되면 합격 절기 위에 6단 효과가 그대로 얹힌다.

## 2. 단전 한도 판단

`sim/meta.md` 를 오늘 데이터로 다시 돌렸다(바뀐 숫자 없음). 연무장은 20항목·최대 레벨 합 59. 봉인석 일곱이 모이는 생에 산 레벨은 34~42(첫 생 버팀 12·8·6분), 그 뒤로 한 생에 한 레벨쯤 늘어 60생 안팎에 다 산다. 천하 확장(2026-11-18)으로 한 혼이 60~100생을 사는 것이 목표 곡선이 되었으니, 안 ⑥이 걱정한 '다 사면 너무 쉬워지는 문제'가 실제로 온다.

- **추천: 넣는다.** 한도는 연무장 레벨 합으로 센다. 처음 **20**, 처음 오른 경지마다 **+5**(이류~현경 여섯 번 → 50), 진엔딩 뒤 제한 없음(59). 한도 안에서 경맥도의 혈을 켜고 끈다(산 레벨은 그대로, 켠 것만 생에 든다). 비싼 셋(분광·경공 충전·재기, 큰 혈)은 한 혈에 레벨만큼 센다.
  - 까닭: 봉인석 일곱 무렵(34~42 레벨) 한도가 이미 40~50이라 이야기 진행은 거의 막지 않고, 다 산 뒤에만 '고르는 일'이 생긴다. 혈서(안 ⑧) 전까지 반복 플레이의 빌드 축이 된다.
- 다른 안: 넣지 않는다(연무장 값을 줄이거나 최대 레벨을 늘려 다 사는 시점을 100생 뒤로 미룬다) / 한도를 경지 대신 윤회의 기 누적으로 늘린다.
- 넣으면 바뀌는 것: 기획서 10장 연무장 절·경맥도 절, Core `Soul.Training` 에 켠 것 목록, 저장 칸, `sim/meta.md` 가정(켠 레벨만 버팀 분에 셈). Unity 경맥도 화면에 켜고 끄기.
