# 메타 곡선 시뮬레이션(T-18)

`dotnet run --project core/BloodRain.Sim -- --meta docs/design/sim/meta.md` 로 다시 만든다. 가정은 `core/BloodRain.Sim/MetaSim.cs` 맨 위, 한 생은 `CheonhaSim`(cheonha.md)과 같다.

시뮬레이터에는 플레이어가 맞는 모형이 없어서 생의 길이를 '첫 생 버티는 분 + 산 연무장 레벨마다 0.5분'으로 가정했다. 첫 생이 몇 분 버티는지는 플레이해 봐야 아니까 6·8·12분 셋으로 흔든다. 종장은 넣지 않았다(봉인석 7개가 모인 생까지).
