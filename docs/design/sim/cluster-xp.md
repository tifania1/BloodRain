# 덩이와 처치 진기 점검(T-19)

`dotnet run --project core/BloodRain.Sim -- --cluster-xp docs/design/sim/cluster-xp.md` 로 다시 만든다.

천하에서는 경지가 오를수록 적 하나가 덩이(4·9·16·28·44·64명)로 나오지만 덩이 하나의 기혈과 진기는 적 하나 값이다(cheonha.json cluster). 그래서 화면 위 개체 수·기혈·진기는 1장 무리 모형과 같고, 다른 점은 지역 혈운 농도(적 기혈·마교 혈공)와 30분 길이다. 아래는 숭산 소림으로 태어나 30분을 돌린 Core `Life` 의 레벨이다(CheonhaSim, 땅의 주인 싸움 포함).

목표(11장): 5분 Lv15, 10분 Lv30, 15분 Lv45, 20분 Lv60, 30분 Lv90(현경). 조정 시험의 뜻은 `Scenarios.cs` 와 level-curve.md.
