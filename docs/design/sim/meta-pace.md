# 메타 진행 속도 조정안(R-02)

`dotnet run --project core/BloodRain.Sim -- --meta-pace docs/design/sim/meta-pace.md` 로 다시 만든다. 코드는 `core/BloodRain.Sim/MetaPaceSim.cs`, 생을 잇는 방식은 `MetaSim`(meta.md)과 같다.

목표(10장): 첫 절정 2~4생, 첫 봉인석 3~6생, 봉인 엔딩(봉인석 7 + 종장) 15~20시간. 시간은 서장 10분 + 생마다 버틴 분 + 객잔 1분만 센 것이라 실제 플레이는 이보다 길다(메뉴·대화·실패한 보스전·종장은 빠짐). 한 안에 80생까지 돌린다.

## 왜 빠른가(지금 데이터, 첫 생 8분)

- 봉인석은 땅의 주인을 처음 쓰러뜨릴 때 바로 하나씩 나온다. 한 생에 여럿을 잡으면 한꺼번에 모인다. 가장 많이 잡은 생은 22생(현경)의 7명이다.
- 화경 장막에는 일곱 땅이 모두 든다(7장). 처음 화경에 오른 12생(2.7시간) 뒤로 봉인석 5개가 나머지 생에서 모였다. 봉인석이 모이는 속도는 '언제 화경·현경에 닿는가'가 정한다.
- 연무장을 생마다 다 사서 버티는 분이 0.5분씩 늘고(가정), 버틴 분이 길수록 경지가 오른다. 봉인석 7개 때 연무장 레벨은 40.
- 첫 봉인석은 6생으로 목표(3~6생) 안이다. 앞쪽은 맞고 뒤쪽(4개째부터)이 빠르다.
