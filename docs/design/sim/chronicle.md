# 천하 연표 시뮬레이션(GU-11e)

`dotnet run --project core/BloodRain.Sim -c Release -- --chronicle docs/design/sim/chronicle.md` 로 다시 만든다. 코드는 `core/BloodRain.Sim/ChronicleSim.cs`, 판정은 Core `World.Chronicle`, 사건은 `chronicle.json`(설계안 `docs/design/cheonha_expansion_full.md` '예시: 숭산에서 태어난 생').

몸마다 [cheonha.md](cheonha.md) 와 같은 한 생(정책 average, 처음 혼, 성질 없음, 30분)을 시드 1~30 돌려 경지 도달 시각을 얻었다. '닿음'은 사건 시각에 혈우 장막이 그 자리를 덮는다는 뜻이고 걸어가는 시간은 넣지 않았다. 값은 고치지 않았다.

## 읽을 것

- 지금 데이터로는 숭산 몸 첫 생이 설계안에서 '늦음'이던 개방 총타·무당산·당가타에도 대개 제때 닿는다. 경지 도달이 7장 목표보다 1~5분 이르기 때문이다(처치 진기, P-02). 이대로면 '회귀할수록 더 먼 사건에 닿는다'는 뼈대에 남는 자리가 없으니, 연표 시각은 P-02 가 정해진 뒤 도달 시각에 맞춰 다시 잡는다.
- 개방 총타(6:00)는 일류 도달(가운데 5:52)과 8초 차이라 판마다 갈린다. 시각을 한 번 고칠 때 가장 먼저 볼 줄이다.
- 세 몸의 도달 시각이 같은 것은 CheonhaSim 이 개방·남궁 출생도 숭산(chapter1) 적 값으로 돌리기 때문이다(cheonha.md 가정). 몸마다 다른 것은 거리뿐이다.
- 남궁 몸은 숭산 아랫마을·개방 총타·무당산 세 사건에 첫 생부터 못 닿는다(멀어서). 몸마다 닿는 사건이 갈리는 것은 설계안 의도대로다.
