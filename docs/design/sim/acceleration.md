# 회귀 가속 시뮬레이션(GU-11f)

`dotnet run --project core/BloodRain.Sim -c Release -- --acceleration docs/design/sim/acceleration.md` 로 다시 만든다. 코드는 `core/BloodRain.Sim/AccelerationSim.cs`, 규칙은 Core `Progression.PastLifePower`(설계안 `docs/design/cheonha_expansion_full.md` '전생의 공력 (추천 규칙)').

한 판 시뮬레이터(진소운, 정책 average, 숭산 적 값, 30분)를 시드 1~30 돌린 가운데값. 지난 생은 모두 현경까지 올랐다고 쳐서 화경 → 현경 구간만 제 속도다. 연무장은 0(공력의 '빠르기'만 떼어 봄). 값은 고치지 않았다.

## 읽을 것

- 정한 규칙(4%·상한 60%, 2026-11-20)이면 마친 생 15번째쯤 상한에 닿는다. 일류 5:53 → 3:32로 멈추고, 목표 곡선의 30생(3:30)에 거의 맞는다. 60·100 생(2:15·1:30)은 진기 감소가 아니라 '그 경지로 깨어난다'(30번 넘은 구간)가 맡는다(decisions #62). 필요 진기를 60% 줄여도 시간이 60% 주는 것은 아니다(앞부분은 화력이 진기 흐름을 정하고, 레벨이 빨리 올라도 처치가 그만큼 늘지 않는다).
- 아래 두 안(옛 설계안 상한 30%·1%·상한 80%)은 견주려고 둔 것이다.
- 지금 데이터는 첫 생부터 일류 5:53·절정 9:19로 7장 목표(6:40·11:40)보다 이르다(처치 진기, P-02). 그래서 '마친 생 0' 줄이 목표 곡선 1~5 줄보다 앞서 있다.
- 감소율·상한은 2026-11-20 사람이 추천대로 정했다(backlog GU-11f1). 한 생(Life)이 혼의 전생의 공력을 RunXp 에 건다.
