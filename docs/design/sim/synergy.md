# 연환·진전 화력 상한(S-05)

`dotnet run --project core/BloodRain.Sim -- --synergy docs/design/sim/synergy.md` 로 다시 쓴다. 손으로 고치지 않는다.

## 어떻게 쟀나
- 무공 6칸 조합 8,008가지를 모두 Lv8(절기 전)로 두고, 보스 한 마리에게 들어가는 초당 피해를 웹 프로토타입 동작 식(WeaponModel)으로 계산했다. 프로토에 동작이 없는 무공 8종은 시뮬레이터의 대충 값이다.
- 심법 6칸은 화력 진전(화산·당가·남궁·개방·곤륜) 쪽으로 가장 세게 채운 경우를 골랐다. 심법 자체 능력치는 양쪽에 똑같이 들어간다고 보고 뺐다. 삼재검법이 있으면 '기본의 극' 한 칸을 가장 이로운 문파에 준다.
- 배수 = (시너지 없는 화력 + 연환·진전이 보탠 화력) ÷ 시너지 없는 화력. 평균 빌드가 11장 화력 목표에 맞는다고 보면 이 배수가 곧 목표 대비 %다.
- 연환·진전 효과는 글로만 적혀 있어 화력으로 바꾸는 식을 스스로 정했다(`SynergyCheck.cs` Eval). 범위·제어·흡혈·생존 효과는 보스 한 마리 화력에 0으로 셌다. 인뢰검(원 안 감전)과 혈창(3초 출혈)은 보스에게도 들어가는 피해지만 식을 정하지 않아 0으로 셌으니, 두 연환이 든 조합은 실제보다 조금 낮게 나온 값이다.
- '조건부'는 늘 켜져 있지 않은 것: 개방 3단계(기혈 30% 아래 공력 +30%), 곤륜 3단계(강시 계열에 +25%).
