# 캐릭터별 절기 각성 시각

`dotnet run --project core/BloodRain.Sim -c Release -- --awakenings docs/design/sim/awakenings.md` 로 다시 쓴다. 코드 `core/BloodRain.Sim/AwakenSim.cs`.
RunSimulator(숭산 무리 모형, 평균 정책) 30분 × 캐릭터 8명 × 시드 10. 절기 문턱·그릇·각성은 Core `Loadout` 그대로. level-curve.md 는 진소운 한 사람이라 여덟 명을 나란히 놓았다.
레벨업에는 처음부터 열린 무공만 나온다(시작 무공은 열렸든 아니든 들고 시작한다).

목표는 기획서 8장: 첫 절기는 절정 무렵(약 11.7분)이나 15분 보갑, 둘째는 초절정 돌파(약 16.7분). 일부 판만 닿았으면 (닿은 판/전체).

## 읽는 법

- 첫 절기는 혜공이 가장 이르고(10.3분) 남궁현이 가장 늦다(12.0분). 목표(11.7분)보다 3분 넘게 늦은 캐릭터: 없음.
- 30분에 절기를 넷 다 채운 캐릭터: 진소운·남궁현·혜공·당연화·하연·운화·마칠·백야. 넷째 그릇은 현경(레벨 90)에서 열리니, 숭산 무리 모형에서 30분 안에 현경에 닿는지가 먼저다.
- 첫 절기가 시작 무공인 판은 14/80뿐이다. 평균 정책은 시작 무공을 따로 아끼지 않고 무공 넷을 먼저 채운 뒤 보이는 강화를 고르기 때문이다(한 판 표를 찍어 보면 10분에 시작 무공이 Lv2~3 인 판이 흔하다). 사람은 시작 무공을 먼저 키울 때가 많아서 실제로는 이보다 자주 시작 무공이 먼저 깨어날 것이다. 정책 하나로 본 것이니 결론으로 쓰지 않는다.
- 빠진 것: 처음엔 안 열린 무공(태극검·쇄겸술·혈조·음공·이화창·뇌부·낙화검우)은 레벨업에 안 나온다. 도감을 채운 뒤에는 고를 무공이 늘어 짝 맞추기가 조금 늦어질 수 있다.
