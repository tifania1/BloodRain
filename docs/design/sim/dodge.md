# 땅의 주인 패턴 피하기

`dotnet run --project core/BloodRain.Sim -- --dodge docs/design/sim/dodge.md` 로 다시 쓴다. 코드는 `core/BloodRain.Sim/DodgeSim.cs`.

예고가 뜬 순간 플레이어가 노림 자리에 서 있다고 보고, 판정 밖으로 나가는 가장 짧은 거리(몸 반지름 0.4m 포함)를 Core `BossPatterns` 판정 그대로 쟀다. 걸음은 이동속도 100 = 초속 4.6m(축척 배율 1), 경공은 0.25초에 4.0m 하고 남은 예고 시간은 걷는다. 경공 무적은 0.2초, 충전 2회, 하나 차는 데 4초.

## 읽는 법

- 걸어서 절반도 못 피하는 것: 혈영회주 혁련휘 순간이동(3.9m 대 2.8m), 혈영회주 혁련휘 순간이동(3.9m 대 1.8m). 이 패턴들은 노림 자리에 서 있으면 경공이 있어야 거리로 빠진다.
- 경공을 섞어도 절반을 못 피하는 것: 없음.
- 경공은 4초에 하나씩 찬다(초당 0.25번). 패턴 간격이 4.0~4.5초(2막 3.0~3.5초)라 세 패턴 가운데 하나만 경공이 필요하면 충전이 남고, 내려찍기처럼 한 시전에 여러 번 필요하면 충전 2회가 바로 바닥난다. 걸어서 못 피하는 줄 수: 혈영회주 혁련휘 2.
- 혈영회주 혁련휘 순간이동은 한 시전에 4번 내려찍는데 둘째부터는 0.4초 간격이라 걸어서는 1.8m 뿐이다(빠져나갈 거리 3.9m). 경공 2회를 다 써도 2번은 무적(0.2초)을 판정 순간에 맞추거나 맞아야 한다. 뒤 내려찍기가 어디를 노리는지(앞 내려찍기 자리, 지금 자리)는 데이터에 없어 Unity 구현 때 정해야 한다.
- 혈귀 마천패 역류 파도는 서서 무적으로 버티면 띠가 몸을 지나는 0.28초가 무적 0.2초보다 길어 맞는다. 띠 쪽으로 경공해야(0.13초) 뚫린다. 판 전체를 쓰는 띠라면 피하는 길은 이것뿐이니 튜토리얼 문구나 예고 그림이 '파도 쪽으로'를 알려 줘야 한다.
- 탄 틈은 탄 크기를 0으로 본 값이라 실제는 더 좁다. 부채꼴 암기는 보스에서 4.6m 안, 매화검기 방사는 보스에서 3.1m 안이면 틈이 몸 너비보다 좁아 사이로 못 빠진다. 탄 판정 크기를 데이터에 넣어야 다시 잴 수 있다.
- 위 거리는 '노림 자리에 가만히 서 있다가 예고를 보고 움직인다'일 때다. 늘 움직이며 싸우면 대개 이보다 짧다. 반대로 적 무리에 막혀 길이 없으면 더 멀다.
- 시뮬레이터 가정: 몸 반지름 0.4m, 이동속도 100 = 초속 4.6m, 예고 시작과 동시에 움직인다(반응 시간 0), 경공 무적을 판정 순간에 맞추는 길은 '무적으로 버티기' 표에만 셌다.
