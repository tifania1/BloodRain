# 음양 게이지 흐름 시뮬레이션

> 자동 생성: `dotnet run --project core/BloodRain.Sim -c Release -- --yinyang docs/design/sim/yinyang.md`. 손으로 고치지 않는다.

숭산 무리 모형(`RunSimulator`)을 30분 돌리며 Core `YinYangGauge`·`Backlash` 로 게이지가 어느 구간에 머무는지 잰다. 캐릭터 8명 × 정책 3개 × 시드 1~10.

규칙(balance.json `yinyang`): 무공 레벨당 ±5, 심법 레벨당 ±8(센 심법은 데이터 값), 태극 ±25(무당 운화는 characters.json 값), 극성 ±70부터, 극성에 60초 머물 때마다 기혈역류.

빠진 것: 마교 몸의 혈공(심마), 영약·태극 바닥·역근·태극환 같은 되돌림, 다시 고르기·파기. 정책은 음양을 보지 않고 고른다. 그래서 이 표는 '음양을 신경 쓰지 않는 사람'의 게이지다. 역류는 경공으로 끊지 않는다고 셌다(끊어도 다음 역류까지 60초는 같아서 횟수는 같다).

## 읽은 것

- 모든 줄을 고르게 평균하면 태극 32%, 편향 32%, 극성 36%. 한 판 역류는 평균 10.2번, 많은 판은 25번.
- 극성에 가장 오래 머문 줄: 남궁현(+10) average 54%. 가장 짧은 줄: 운화(0) slow 20%.
- average 정책에서 처음 태극을 벗어나는 분(캐릭터별 가운데값)은 2.0~5.4분. 기획서 4장 '서장 상세 흐름'은 7:30에 '음양 게이지가 처음 기울며 짧은 설명'을 둔다. 다만 이 시뮬레이터는 레벨이 기획 목표보다 빠른 지금 처치 진기(P-02 미정, level-curve.md)로 돈다. 벗어나는 분은 레벨업 횟수를 따라가니 P-02 가 정해지면 늦어진다.
- 처음부터 열린 무공 9종은 양 5·음 2·중 2, 심법 16종은 양 5·음 6·중 5. 카드가 양 무공을 더 자주 내밀어 게이지가 대개 양 쪽으로 간다. 음에서 시작한 몸도 average 로는 당연화(-10→+92), 백야(-15→+40)로 넘어간다.
- 20분부터는 칸이 차고 레벨이 다 올라 게이지가 거의 멈춘다(average 가운데값이 20분과 30분에 같은 캐릭터 8/8). 그때 극성에 있으면 판 끝까지 60초마다 역류가 온다. 멈추는 분도 레벨 속도(P-02)를 따라 움직인다.
- 정책이 음양을 보지 않으니 극성 비율은 '모르고 해도 이만큼은 미친다'는 아래쪽 값이다. 일부러 한쪽으로 모으면 더 오래, 맞추려 들면 더 짧아진다.
