# 사람 결정 묶음: 처치 진기(P-02) · 땅의 주인(T-40) · 혈공(T-41)

> 자동 생성: `dotnet run --project core/BloodRain.Sim -c Release -- --decisions docs/design/sim/decisions.md`. 손으로 고치지 않는다.

셋 다 backlog 에서 사람 결정을 기다린다. 처치 진기를 줄이면 레벨·화력이 늦어져 땅의 주인 처치 시간이 바뀌고, 혈공은 진기에 농도를 곱하니 처치 진기 크기를 그대로 따른다. 그래서 같은 시드(1~3)로 '지금 데이터'와 '처치 진기 줄이기'(Scenarios.cs `kill-xp`, 강시·혈인 1, 목인나한·동갑시 2)를 나란히 돌렸다. 데이터는 바꾸지 않았다.

자세한 근거는 [cluster-xp.md](cluster-xp.md)(P-02), [cheonha.md](cheonha.md)(T-40), [blood-art.md](blood-art.md)(T-41).

## 읽을 것

- 처치 진기를 줄이면 천하 현경 도달이 20:27 → —(12/24판만 30분 안에 닿음). 땅의 주인 첫 싸움은 8.3배 → 10.0배로 더 나빠진다. P-02 만 정하면 T-40 은 저절로 풀리지 않고, 기혈 식이나 깨어나는 경지 쪽을 같이 손봐야 한다.
- 혈공은 지금 데이터에서 기준보다 -8:38, 처치 진기를 줄이면 -14:03. √농도로 바꾸면 각각 -4:18, -6:48. 처치 진기를 줄이면 기준 판이 혈공 판보다 더 많이 늦어져 격차가 오히려 벌어진다. T-41 은 P-02 를 정한 뒤 그 값으로 다시 재야 하는 이유다. 기획서 5장 '숭산 출생과 비슷하게'에 가까운 쪽을 고르면 된다.
- 세 결정을 한 번에 정할 때 이 표를 다시 만들면 된다. 다른 조합(예: 처치 진기 줄이기 + 적 기혈 증가)을 보려면 `DecisionSim.ScenarioIds` 에 Scenarios.cs id 를 더한다.
