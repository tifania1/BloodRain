## 읽기

- 세 몸의 처치 수가 같은 것은 CheonhaSim 이 개방·남궁 출생도 숭산(chapter1) 적 값으로 돌리기 때문이다(cheonha.md 가정). 몸마다 다른 것은 어느 땅에 서 있었나뿐이다.
- 시험 A(지금 데이터): 병기는 숭산 정예 둘째(계율원 강시 승려)·셋째(강시 방장 대리)에게서만 나온다. 생 대부분이 깨어난 땅의 주인을 찾아 숭산을 떠나 넷째·다섯째 정예는 다른 땅에서 보니, 금강 염주 양병~명병에서 멈추고 신병은 0. 6단은 지금 데이터로는 나오지 않는다.
- 개방·남궁 땅에는 병기 `guaranteed`·`droppers` 가 비어 있어 제 땅에서는 병기가 나오지 않는다. 숭산으로 걸어가 만난 정예가 떨군 금강 염주만 쥔다(소림 무공에만 듦). 남궁 몸은 숭산에서 멀어 80% 가 빈손.
- 시험 B: 기획서 8장은 '정예는 확정', sinbyeong.md 는 '한 번 확정' 이라 다르다. 지금 Core 는 매번(A). 한 번으로 하면 정예만으로는 양병이 끝이다.
- 시험 C: 문파 땅에서 혈강시 몫이 한 생에 1만 마리 남짓이라 설계안이 짐작한 1,200마리의 아홉 배쯤이다. 그래서 0.15% 는 한 생에 열여섯 번쯤 줍고 절반 넘게 신병이 된다. '운이 보통이면 양병~명병, 잘 풀린 생에만 신병'에 가까운 것은 0.03~0.05%.
- 시험 C 의 확률 줄은 decisions #60 이 추천대로 정해졌을 때 고를 값의 폭이다.

## 따로 볼 것

- 무명 철검 유품: 원각 계정 첫 처치에 떨어진다. 칸이 하나라 금강 염주를 쥔 소림 생이 그것을 주우면 범병 철검으로 바뀐다(Core `GearSlot.Pick`). 화면에서 자동으로 줍는다면 그 생은 병기를 잃는 셈이니 Unity GU-10U 에서 '쥔 것보다 낮으면 묻고 줍기'나 '유품은 문파 없는 몸만' 같은 길이 필요하다.
