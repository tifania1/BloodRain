# 천하 한 생 시뮬레이션(T-17)

`dotnet run --project core/BloodRain.Sim -- --cheonha docs/design/sim/cheonha.md` 로 다시 만든다. 가정은 `core/BloodRain.Sim/CheonhaSim.cs` 맨 위.

문파마다 정책 average, 시드 1~5의 가운데값. 진소운 시작 무공, 출생지 성질 없음, 처음 혼(연무장 0). 화력·진기는 level-curve 와 같은 무리 모형이라 **처치 진기가 높은 지금 데이터(B-07)를 그대로 따른다**. 보스전은 실제 치는 시간 70%로 잡았다.

## 읽을 것

- 현경 도달은 마교 빼고 가운데 20:32(목표 30:00). 처치 진기가 많은 지금 데이터 탓이고 B-07·P-02 와 같은 이야기다. 마교는 혈공(진기 × 혈운 농도)이 겹쳐 더 빠르다.
- 출생지 땅의 주인 첫 싸움이 목표 처치 시간의 5.6~20.0배(가운데 11.7배) 걸린다. 땅의 주인은 절정에 깨어나는데 보스 기혈 식(7장, 20분 화력 기준 ÷ 2.6)이 그 무렵 화력보다 천천히 줄어서다. 깨어나는 경지를 늦추거나, 기혈 식을 싸움 시작 분의 화력에 맞추거나, 처치 시간 목표를 늘리는 쪽 중 하나를 골라야 한다(사람 결정).
- 땅의 주인은 절정·초절정에 한꺼번에 깨어나지만 30분 안에 실제로 싸움을 거는 수는 문파마다 다르다(시드 1: 소림 6, 개방 6, 남궁 5, 당가 6, 수로채 2, 무당 1, 화산 1, 곤륜 1, 마교 1). 첫 싸움이 길면 다른 땅을 거의 못 밟는다.
