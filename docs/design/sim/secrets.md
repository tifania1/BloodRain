# 비전: 무공 구성은 언제 갖춰지나

`dotnet run --project core/BloodRain.Sim -c Release -- --secrets docs/design/sim/secrets.md` 로 다시 쓴다. 코드 `core/BloodRain.Sim/SecretSim.cs`.
레벨업 추첨은 Core `Loadout.RollLevelUp`, 판정은 Core `SecretChecker` 그대로. 무공은 전부 열렸다고 보고(도감을 거의 채운 사람), 레벨업 차례마다 몇 분인지는 RunSimulator(숭산, 평균 정책) 30분 레벨 곡선 가운데값(시드 5)으로 바꿨다. 비전·캐릭터마다 200판.
고르는 사람은 노리는 비전에 든 무공·심법이 보이면 먼저 받고 목표 레벨까지 올린다. 파기 0, 기연 0(카드 3장). 다시 고르기는 0번과 연무장 최대를 나란히 놓았다.

## 1. 비전마다

캐릭터는 시작 무공이 조건에 든 몸(없으면 진소운). '구성'은 무공·심법 레벨(무명검은 무공 하나만)까지, '열림'은 Core 판정이 실제로 연 것이다. 사건·횟수·문파 몸·깬 장이 붙은 비전은 이 시뮬레이터가 그 몫을 못 채워서 열림이 늘 '-'다(표에 *).

'칸 막힘'은 30분에 노리는 무공·심법을 못 가졌는데 그 칸이 이미 다른 것으로 찬 판이다(받고 싶은 카드가 하나도 없는 차례에 어쩔 수 없이 받은 것). 오른쪽 둘은 연무장 다시 고르기 최대(5번)를 그런 차례에 쓴 것.

| 비전 | 캐릭터 | 구성 갖춘 판 | 구성 분(가운데값) | 열린 판 | 열린 분 | 칸 막힘 | 다시 고르기 5: 구성 | 열린 판 |
|---|---|---|---|---|---|---|---|---|
| 낙매검선의 피* | 진소운 | 168/200 | 11.1 | - | - | 32/200 | 199/200(11.3분) | - |
| 어강술* | 하연 | 162/200 | 3.5 | - | - | 38/200 | 200/200(3.7분) | - |
| 매화삼롱 | 진소운 | 146/200 | 10.5 | 146/200 | 10.5 | 54/200 | 199/200(10.7분) | 199/200 |
| 무극 | 운화 | 195/200 | 10.8 | 49/200 | 20.9 | 5/200 | 200/200(10.8분) | 52/200 |
| 취선* | 마칠 | 195/200 | 2.7 | - | - | 5/200 | 200/200(2.8분) | - |
| 혈해마공 잔편* | 백야 | 197/200 | 2.7 | - | - | 3/200 | 200/200(2.7분) | - |

무공 구성 조건이 없는 비전(역천)은 뺐다. 역천의 역류 횟수는 yinyang.md 를 본다.

## 2. 무명검 고칠 방향별 (S-07)

backlog S-07 의 셋을 같은 시드 200판으로 돌렸다(진소운). (가)는 카드 석 장이 모두 새 무공일 때 은자·음식 카드가 섞여 나와 그걸 받는다고 두었다(무공·심법은 그대로). (다)는 이 시뮬레이터에 파기가 없어서 '받고 싶은 카드가 없을 때 쓰는 다시 고르기'를 그만큼 준 것으로 갈음했다.

| 방향 | 열린 판 | 열린 분(가운데값) | 새 무공을 억지로 받은 판 |
|---|---|---|---|
| 지금(10분) | 0/200 | - | 200/200 |
| 지금 + 다시 고르기 5 | 0/200 | - | 200/200 |
| (가) 새 무공뿐이면 은자·음식 | 200/200 | 11.5 | 0/200 |
| (나) 7분 | 0/200 | - | 200/200 |
| (나) 5분 | 0/200 | - | 200/200 |
| (나) 5분 + 다시 고르기 5 | 0/200 | - | 200/200 |
| (다) 파기·다시 고르기 15 | 43/200 | 10.0 | 200/200 |
| (다) 파기·다시 고르기 30 | 162/200 | 10.0 | 200/200 |

- (가)만 판마다 연다(200/200, 가운데 11.5분). 10분보다 늦는 건 삼재검법 Lv8 이 그때쯤 차서다. (나)는 5분으로 줄여도 0/200: 삼재검법이 Lv8 에 닿기 전에 석 장이 모두 새 무공인 차례가 먼저 온다. (다)는 받고 싶지 않은 차례를 30번 넘겨야 162/200이고, 연 뒤엔 결국 새 무공을 받는다(보상은 그 뒤에도 남는다).

## 읽는 법

- 무명검(진소운): 새 무공을 피해도 200/200판은 고를 것이 새 무공뿐인 차례가 와서 억지로 받았다. 열린 판 0/200, 다시 고르기 5번이어도 0/200. 무공 칸이 비어 있는 동안 카드 석 장이 모두 새 무공인 차례가 자주 오고, 운이 좋아도 받을 수 있는 강화가 삼재검법 7번 + 심법 6칸 × 5단계 = 37번뿐이라 레벨 38(진소운 곡선으로 10.0분)부터는 새 무공 말고 고를 것이 없다. 10분을 넘기려면 그 뒤로 남은 레벨업마다 파기나 다시 고르기가 있어야 한다. 조건(10분)이나 '새 무공 카드 대신 은자·음식' 같은 빠져나갈 길을 정하지 않으면 사실상 못 여는 비전이다.
- 무극(운화): 구성은 10.8분쯤 갖추지만 게이지가 0에 3분 머문 판은 49/200. 게이지는 레벨업으로만 움직여서, 무공·심법이 다 차 레벨업이 멈춘 뒤 0에 서 있으면 열리고 아니면 안 열린다. 역근(게이지 0으로)을 넣으면 더 쉬워진다. 다시 고르기 5번이면 52/200.
- 사건 조건이 붙은 비전(*)은 구성 분이 '여기서부터 사건을 기다릴 수 있다'는 뜻이다. 사건이 얼마나 자주 나는지(정신부·음식·보갑·의서)는 데이터에 개수가 없어 재지 않았다.
- 다시 고르기는 낙매검선·어강술·매화삼롱처럼 정해진 무공·심법 셋을 모아야 하는 비전에서 '칸 막힘'을 거의 없앤다. 다시 고르기가 없는 첫 몇 생에는 이 비전들이 네 판에 한 판꼴로 칸이 막힌다.
- 빠진 것: 보갑 강화, 초절정 7칸째, 파기, 기연 4장째. 모두 넣으면 구성 분은 더 이르다. 무공이 덜 열린 사람은 노리는 무공이 아예 안 나올 수 있다(이 표는 다 열린 경우).
