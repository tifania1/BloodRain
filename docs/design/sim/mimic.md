# 혈영 분신이 흉내 낸 무공의 피해

`dotnet run --project core/BloodRain.Sim -c Release -- --mimic docs/design/sim/mimic.md` 로 다시 만든다(`MimicSim.cs`).

혈영 분신은 플레이어 무공을 같은 레벨로 흉내 낸다(Core `Mimicry`, 기획서 6·10장). 피해는 무공 기본 피해 × 배율이고 플레이어 심법·문파 보너스는 안 받는다. 잡몹 분신(enemies.json)은 시작 무공 하나를 피해 0.3배·쿨 2배로, 혈영회주가 부르는 분신(bosspatterns.json `mirror_clone`)은 가진 무공 모두를 피해 0.05배·쿨 1배로 12초 동안 쓴다.

## 가정

- 한 번 발동에 몸에 들어가는 대 수는 시뮬레이터 `WeaponModel` 이 보스 한 마리를 칠 때 쓰는 값(SingleHits)을 그대로 빌렸다. 분신이 플레이어를 보고 서 있고 플레이어가 하나도 안 피하는 경우라 **위쪽 값**이다.
- 대마다 호신을 뺀다(`Damage.Taken`, 최소 피해 1). 지속 피해(화상·중독)는 호신을 안 뺐다.
- 독무처럼 쿨다운 0(상시)인 무공은 닿는 간격(tickSeconds)에 쿨 배율을 곱했다. Core `Mimicry` 도 같은 값을 `Interval`(상시 무공이면 `Aura`)로 준다.
- 절기로 각성한 무공도 각성 전 바탕 무공으로 셌다(Mimicry 규칙). 분신 피해는 분·혈운 농도로 커지지 않는다(Mimicry 에 그런 배율이 없다). 보스 패턴은 `BossPatterns.ScaleDamage` 로 커진다.
- 호신 세 경우는 contact.md 와 같다: 맨몸 0, 연무장 3, 최대 10.

## 혈영회주 자신의 패턴과 견주기

## 읽는 법

- 지금 값(0.05, 2026-11-05 사람이 backlog C-14 추천대로 정함)이면 맨몸 가장 센 조합이 초당 43.9, 가장 약한 조합은 10.3로 30분 보스 패턴 한 바퀴 초당 17.2의 2.6배 · 0.6배다. 다 맞는다는 위쪽 값이라 실제로는 패턴과 비슷한 무게다.
- 까닭: 플레이어 무공 피해는 무리와 보스 체력(수백~수천)을 깎도록 맞춰져 있고 몸 기혈은 100 안팎이다. 같은 숫자를 절반만 줄여 몸에 넣으면 단위가 맞지 않았다(옛 값 0.5).
- 호신 최대(10)에서 작은 타를 여러 번 넣는 무공(나한권·태극검·섬광지 등)은 대마다 최소 피해까지 깎여 크게 약해진다. 한 방이 큰 무공은 덜 깎인다. '빌드의 약점을 그대로 갖는다'는 취지와는 맞는 방향이다.
- 잡몹 분신은 사정이 다르다. 지금 값(0.3·쿨 2배)이면 가장 센 시작 무공(혈조)으로도 초당 25.0에 그쳐 분신 몸이 붙어서 치는 접촉 초당 113.8의 0.22배다. 접촉보다 훨씬 약하니 무공 쪽 배율을 더 내릴 까닭은 적고, 멀리서도 맞는다는 점만 남는다.
- 분신은 분·농도로 커지지 않아 늦게 싸울수록 보스 패턴보다 상대적으로 약해진다. 대신 플레이어 무공 레벨을 따라가니 빌드가 클수록 세다.
