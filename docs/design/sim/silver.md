# 한 생의 은자(RM-06)

숭산 무리 모형(`RunSimulator`)을 20분, 정책 average, 시드 1~10의 가운데 처치 수에 은자 규칙을 기댓값으로 얹었다. 10장 화폐 표의 목표는 **20분 600~900**.

## 요약

- 지금 데이터로 20분 은자는 약 **7,785냥**, 목표의 8.6배(위쪽 끝 기준). 거의 다 잡몹 주머니(97%)다: 처치 20,957 × 1.2% × 주머니 30냥.
- 처치 진기 줄이기(P-02 안)로도 20분 처치가 19,846마리로 7,385냥. 은자는 처치 진기와 따로 맞춰야 한다.
- 등롱(140냥)과 금두꺼비(100냥)만 치면 240냥으로 목표 아래쪽 끝의 40%다. '잡몹이 1.2% 확률로 은자 주머니'(8장 드롭 표)는 웹 프로토타입에서 돌던 값이고, 화면 적이 수백인 무리 모형에선 처치가 2만을 넘어 주머니가 너무 많이 나온다.
- 목표 가운데(750냥)에 맞추려면 잡몹 주머니 확률이 약 0.081%(지금의 7%)여야 한다. 맞추는 안은 backlog RM-06a(사람 결정 대기).

## 가정

| 항목 | 값 | 출처 |
|---|---|---|
| 잡몹 주머니 확률 | 1.2% | balance.json `drops.enemySilverChance` |
| 주머니 은자 | 10~50(가운데 30) | balance.json `drops.silverBag` |
| 등롱 | 33초마다 하나, 다 부숨. 은자 주머니 13% | 웹 프로토타입 `template.html` 등롱 생성, balance.json `drops.lantern` |
| 금두꺼비 | 10~12분 창에 한 번, 잡는다고 봄 | chapters.json life `toad`, enemies.json `golden_toad.reward.silver` |
| 처치 | 무리 모형 한 마리 단위 | `RunSimulator`(level-curve.md 와 같은 모형) |

빠진 것: 은자 카드, 탐욕(연무장 +10%/레벨·성질), 혈월 1.5배, 보부상에서 쓴 은자, 천하 판 덩이(사람 수) 셈.

다시 만들기: `dotnet run --project core/BloodRain.Sim -c Release -- --silver docs/design/sim/silver.md`
