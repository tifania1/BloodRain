# 혈마의 그림자 떼어 내기 (밸런스 시뮬레이션)

`dotnet run --project core/BloodRain.Sim -c Release -- --shadow docs/design/sim/shadow.md` 로 다시 쓴다. 코드는 `core/BloodRain.Sim/ShadowSim.cs`.

기획서 7장 '생의 끝': 현경인데 봉인석이 모자라면 30분부터 혈마의 그림자가 쫓아오고 5분마다 강해진다. 버틴 시간이 리더보드에 오른다. 여기서는 그림자 하나만 놓고(다른 적·지형 없음) 곧게 달아나는 몸을 쫓게 해, 처음 붙잡히는 분과 그림자만으로 쓰러지는 분을 잰다. 120분까지만 잰다.

## 고칠 방향별 (T-42)

T-42(2026-11-01 결정: 상한을 없애고 단계마다 몸 가까이 순간이동)를 옛 안과 같은 셈으로 견줬다. 방어는 '보통'. 칸은 '아홉 몸이 그림자만으로 쓰러진 분(가장 이른~가장 늦은)', 괄호는 120분까지 안 쓰러진 몸 수. 순간이동은 단계가 오를 때(5분마다) 0.5초 예고 뒤 몸 뒤 1.0m 로 내려앉는다(이미 더 가까우면 그대로). 목표는 운룡보 Lv5·'둘 다' 몸도 100분 안에 쓰러지는 것.

| 방향 | 맨몸 | 연무장 신법 | 운룡보 Lv5 | 둘 다 |
| --- | --- | --- | --- | --- |
| 지금 데이터(상한 없음 + 순간이동, 단계마다 +8) | 45.5~60.6 | 50.6~66.4 | 66.8~88.0 | 72.5~95.4 |
| 옛 안(상한 125, 순간이동 없음) | 45.9~74.8 (1) | 53.3~74.8 (4) | - (9) | - (9) |
| 상한만 없앰 | 45.9~72.6 | 53.3~86.9 | 86.3~112.5 (2) | 97.5~116.3 (4) |
| 순간이동만(상한 125) | 45.5~58.0 (1) | 50.6~58.0 (4) | - (9) | - (9) |
| 지금 + 단계마다 +12 | 40.6~50.6 | 45.3~55.4 | 55.5~70.3 | 60.3~75.3 |

- 상한만 없애면 단계마다 계속 빨라져 맨몸·연무장 신법은 모두 잡히지만, 운룡보를 든 몸은 그림자보다 빨랐던 30~50분 동안 벌려 둔 거리를 그림자가 다 좁혀야 해서 늦게 잡히거나 끝내 안 잡힌다. 순간이동이 5분마다 그 거리를 없앤다.
- 순간이동 뒤에도 그림자가 몸보다 느린 동안은 한두 대 맞고 경공으로 다시 떼어 낸다. 그래서 버틴 시간의 끝은 '그림자가 지속 속도를 넘는 단계'로 정해지고, 신법을 갖춘 몸이 늦게 쓰러지는 순서는 남는다.
- 이 셈은 그림자가 몸에서 얼마나 멀리 떨어지든 그대로 쫓는다고 둔다. 실제로 그림자가 화면 밖 일정 거리 너머로 못 떨어지게(목줄) 하면 (나)와 같은 쪽으로 움직인다.

## 읽는 법

- 신법 없이 맨몸이면 45.5~60.6분에 그림자만으로 쓰러진다(쓰러진 몸 9/9). 버틴 시간은 30분 뒤로 15.5~30.6분.
- 120분까지 한 번도 안 잡힌 경우: 없음. 가장 느린 몸(90)도 운룡보 Lv5 면 걸음이 126이다. 리더보드 '버틴 시간'은 신법이 좋을수록 길지만 그림자로 끝난다.
- 방어를 다 얹어도 붙잡힌 뒤 평균 4초(길어야 12초) 만에 쓰러진다('최대' 36칸). 그림자가 몸보다 빨라진 뒤엔 경공으로 떼어 내도 곧 다시 붙으니, 버틴 시간은 사실상 '지속 속도가 그림자에 따라잡히는 분'으로 정해진다. 기혈·호신·회복은 거의 보태지 않는다.
- 실제 판에서는 화면 위 적 무리가 길을 막고 그림자 곁에서 다른 적에게도 맞으니, 여기 분은 '그림자만으로'의 위쪽 끝이다. 반대로 지형(물·얼음·장막 잔재)과 기믹은 넣지 않았다.
- 시뮬레이터 가정: 그림자는 10m 뒤에서 나타난다, 몸과 그림자가 0.8m 안이면 붙은 것, 그림자가 1.5m 안으로 오면 충전이 있을 때 경공, 곧은 길로 끝없이 달아날 수 있다(현경엔 장막이 걷힌다), 간격 0.02초.
