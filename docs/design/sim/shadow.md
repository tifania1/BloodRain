# 혈마의 그림자 떼어 내기 (밸런스 시뮬레이션)

`dotnet run --project core/BloodRain.Sim -c Release -- --shadow docs/design/sim/shadow.md` 로 다시 쓴다. 코드는 `core/BloodRain.Sim/ShadowSim.cs`.

기획서 7장 '생의 끝': 현경인데 봉인석이 모자라면 30분부터 혈마의 그림자가 쫓아오고 5분마다 강해진다. 버틴 시간이 리더보드에 오른다. 여기서는 그림자 하나만 놓고(다른 적·지형 없음) 곧게 달아나는 몸을 쫓게 해, 처음 붙잡히는 분과 그림자만으로 쓰러지는 분을 잰다. 120분까지만 잰다.

## 고칠 방향별 (T-42)

backlog T-42 의 (가)·(나)를 같은 셈으로 돌렸다. 방어는 '보통'. 칸은 '아홉 몸이 그림자만으로 쓰러진 분(가장 이른~가장 늦은)', 괄호는 120분까지 안 쓰러진 몸 수. (나)는 단계가 오를 때마다(5분마다) 그림자가 몸 뒤 1.0m 로 내려앉는다고 두었다. (다)는 지금 줄과 같다.

| 방향 | 맨몸 | 연무장 신법 | 운룡보 Lv5 | 둘 다 |
| --- | --- | --- | --- | --- |
| 지금(상한 125) | 45.9~74.8 (1) | 53.3~74.8 (4) | - (9) | - (9) |
| (가) 상한 150 | 45.9~72.6 | 53.3~93.6 | 92.3~118.3 (6) | - (9) |
| (가) 상한 175 | 45.9~72.6 | 53.3~86.9 | 86.3~109.1 (4) | 99.2~115.2 (6) |
| (가) 상한 없음 | 45.9~72.6 | 53.3~86.9 | 86.3~112.5 (2) | 97.5~116.3 (4) |
| (나) 지금 + 단계마다 순간이동 | 45.5~58.0 (1) | 50.6~58.0 (4) | - (9) | - (9) |
| (가)+(나) 상한 150 + 순간이동 | 45.5~60.6 | 50.6~66.4 | 66.9~70.7 (6) | 72.5 (8) |

- 상한을 올리면 단계마다 +8씩 계속 빨라져 맨몸·연무장 신법은 모두 잡힌다. 운룡보를 든 몸은 상한을 없애도 120분 안에 다 잡히지는 않는데, 그림자보다 빨랐던 30~50분 동안 벌려 둔 거리를 그림자가 다 좁혀야 해서다. 신법을 갖춘 만큼 늦게 잡히는 순서는 그대로 남는다.
- 순간이동만 넣으면 그림자가 몸보다 느린 동안은 한두 대 맞고 경공으로 다시 떼어 낸다. 운룡보 몸은 여전히 안 쓰러진다. 대신 맨몸의 끝을 당겨 몸 사이 차이를 줄인다(가장 늦은 몸이 지금보다 이르다).
- 둘을 섞으면 벌려 둔 거리가 5분마다 없어지니 운룡보 몸도 그림자가 몸보다 빨라지는 단계에서 곧 잡히기 시작한다. 그래도 경공이 넷인 '둘 다'는 대부분 버틴다. 버틴 시간의 폭을 정하는 건 상한과 '몸보다 빨라지는 단계'다.
- 이 셈은 그림자가 몸에서 얼마나 멀리 떨어지든 그대로 쫓는다고 둔다. 실제로 그림자가 화면 밖 일정 거리 너머로 못 떨어지게(목줄) 하면 (나)와 같은 쪽으로 움직인다.

## 읽는 법

- 신법 없이 맨몸이면 45.9~74.8분에 그림자만으로 쓰러진다(쓰러진 몸 8/9). 버틴 시간은 30분 뒤로 15.9~44.8분.
- 그림자 속도는 125에서 멈추니 지속 속도가 그보다 빠르면 끝내 안 잡힌다. 120분까지 한 번도 안 잡힌 경우: 운룡보 Lv5 9몸, 둘 다 9몸, 연무장 신법 4몸, 맨몸 1몸. 운룡보 Lv5 하나면 가장 느린 몸(90)도 걸음만으로 상한을 넘는다(126). 리더보드 '버틴 시간'이 그림자로는 끝나지 않고, 다른 적(피해 배율이 5분마다 +0.1)이나 좌화로만 끝난다.
- 방어를 다 얹어도 붙잡힌 뒤 평균 4초(길어야 8초) 만에 쓰러진다('최대' 13칸). 그림자가 몸보다 빨라진 뒤엔 경공으로 떼어 내도 곧 다시 붙으니, 버틴 시간은 사실상 '지속 속도가 그림자에 따라잡히는 분'으로 정해진다. 기혈·호신·회복은 거의 보태지 않는다.
- 실제 판에서는 화면 위 적 무리가 길을 막고 그림자 곁에서 다른 적에게도 맞으니, 여기 분은 '그림자만으로'의 위쪽 끝이다. 반대로 지형(물·얼음·장막 잔재)과 기믹은 넣지 않았다.
- 시뮬레이터 가정: 그림자는 10m 뒤에서 나타난다, 몸과 그림자가 0.8m 안이면 붙은 것, 그림자가 1.5m 안으로 오면 충전이 있을 때 경공, 곧은 길로 끝없이 달아날 수 있다(현경엔 장막이 걷힌다), 간격 0.02초.
