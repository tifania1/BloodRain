# 한 생 60분 시뮬레이션(GU-11h3)

`dotnet run --project core/BloodRain.Sim -c Release -- --cheonha60 docs/design/sim/cheonha60.md` 로 다시 만든다. 코드는 `core/BloodRain.Sim/LongLifeSim.cs`.

천하 확장 설계안이 한 생 상한을 60분으로 늘리고 혈월(30분) 뒤에 '혈월의 밤 2막'을 두기로 했다(2026-11-18 사람). 2막 규칙은 아직 없으니 **지금 규칙을 그대로 60분까지 늘리면** 무엇이 어떻게 가는지만 본다. 숭산 소림, 처음 혼, 정책 average, 시드 1~10 가운데값. 봉인석 0 이라 현경이면 30분부터 그림자. 그림자에 맞는 피해는 넣지 않았다. 값은 고치지 않았다.

## 읽을 것

- 30분 뒤로는 적 수(400)와 적 종류(life 마지막 표)가 그대로라 2막에 새로 나오는 것이 없다. 땅의 주인 기혈 배율만 30분 점(1.31) 뒤로 기울기대로 계속 오른다.
- 레벨은 30분 뒤에도 5분에 10~14씩 계속 오른다(진기 흐름이 그대로라). 2막에서 무엇으로 성장을 보여 줄지(새 깨달음·병기 등)는 아직 없다.
- 봉인석이 모자란 현경은 그림자가 5분마다 세져 60분에 7단계(접촉 피해 곱으로 커짐, 걸음은 플레이어 기본 100보다 빠르고 상한 없음)가 된다. 언제 붙잡히는지는 [shadow.md](shadow.md). 2막을 두려면 그림자 규칙을 2막과 어떻게 나눌지부터 정해야 한다 — 사람 결정 대기 GU-11h4(decisions #64).
