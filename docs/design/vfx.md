# 무공 비주얼 — 단계 규칙과 만드는 법

이 게임의 재미는 무공이 자라는 게 눈에 보이는 데서 나온다. 레벨업이 숫자만 바꾸고 끝나지 않게, 단계마다 화면에서 무엇이 바뀌는지 여기서 정한다.
시안: `web/lookdev/samjae.html` (삼재검법 1단~절기). 공개 주소 https://bloodrain-proto.pages.dev/lookdev/samjae.html

## 단계 규칙 (무공 16종 공통)

단계가 오를 때 아래 '바뀌는 것' 중 둘 이상이 함께 바뀐다.

| 단계 | 언제 | 바뀌는 것 | 색 | 화면 |
|---|---|---|---|---|
| 1단 | Lv 1–3 | 기본 모양 하나 | 먹 | 없음 |
| 2단 | 첫 마일스톤(대개 Lv4) | 개수·방향이 늘고 담채가 번진다 | 먹 + 청회 | 맞은 적 번쩍임 |
| 3단 | 둘째 마일스톤(대개 Lv7) | 연타·잔상, 금빛 비백, 처치 시 두 동강 | 먹 + 금 | 처치 때 0.03초 멈춤, 약한 흔들림 |
| 절기 | 문턱(무공 Lv8 + 짝 심법 Lv3) + 절기 그릇(기획서 8장) | 모양이 아예 바뀌고 무공마다 고유 서예 글자 | 먹 + 금 + 낙관 주홍 | 먹·종이 뒤집기, 0.05초 멈춤(세 번에 한 번) |

마일스톤 레벨은 `weapons.json` 의 `milestones` 를 따른다. 마일스톤이 없는 무공은 Lv4·Lv7로 본다. 마일스톤이 하나뿐이면 Lv7 이상일 때 3단 문턱(2단은 Lv4), 밑이면 2단 문턱(3단은 Lv7)으로 본다. 셋 이상이면 낮은 둘. 셈은 Core `WeaponGrowth.VisualTier`.

## 화면이 어지러워지지 않게

- 주홍은 적의 위험 표시와 절기 낙관에만 쓴다. 플레이어 무공에는 주홍이 없다. 붉은 게 보이면 피하면 된다.
- 뒤집기·글자·낙관 같은 큰 연출은 절기에서도 세 번에 한 번.
- 멈춤(히트스톱)은 0.3초에 한 번까지. 처치마다 멈추면 무리를 벨 때 화면이 계속 끊긴다(시안에서 실제로 그랬다).
- 획은 0.4초 안에 흩어지고 담채와 바닥 먹 자국만 조금 남는다(먹 자국은 8초쯤에 걸쳐 마른다).
- 휴대폰용 '효과 간소화' 설정: 담채·잔상·먹 자국 양을 줄인다. 반투명 겹침이 휴대폰 성능을 가장 많이 잡아먹는다.

## 만드는 법 (시안 → Unity)

| 시안에서 | Unity에서 |
|---|---|
| 붓 터럭을 하나씩 그어 만든 획 그림 | 같은 알고리즘을 파이썬으로 옮겨 `Assets/Art/VFX/Brush/` 에 텍스처로 굽는다. 무공·단계별 2~3장 |
| 부채꼴로 잘라 획이 그어지는 모습 | 셰이더 `_Progress` (각도 마스크) |
| 노이즈로 구멍이 번지며 흩어짐 | 셰이더 `_Dissolve` (노이즈 문턱값) |
| 담채 번짐 | 흐린 복사본 스프라이트, 천천히 커지며 옅어짐 |
| 튀는 먹, 바닥 먹 자국 | 파티클 버스트 + 바닥용 데칼(풀링) |
| 두 동강 | 스프라이트 마스크 두 장으로 반쪽씩 그려 벌림 |
| 먹·종이 뒤집기(탁본처럼 흑백) | URP 전체 화면 패스(Renderer Feature) 0.16초, 반전 후 채도 0 |
| 天地人 글자, 낙관 | 글자는 Yuji Boku 글꼴(TextMeshPro SDF)로 얹고, 낙관 바탕만 텍스처. 글자를 이미지에 굽지 않는다 |
| 히트스톱·흔들림 | 시간 배율 0 + Cinemachine Impulse |
| 빛(번개·검기) | 더하기 섞기 금빛·흰빛 층 + 그 밑에 넓고 흐린 먹 받침 층(보통 섞기). 종이 바닥은 밝아서 빛만 더하면 묻힌다. 수묵화가 흰 것을 둘레 먹으로 살리는 것과 같은 수 |

붓 획 굽기는 `python tools/bake_brush.py`(numpy·Pillow, 시드 고정이라 다시 구워도 같은 그림, `--check` 로 비교). 흰 획 + 알파 512px 를 층마다 따로 굽는다: `stroke`(본 획), `wash`(담채, 2단부터), `gold`(금빛 터럭, 3단부터). 색은 셰이더가 입힌다. 512px 칸 가운데가 몸 위치이고 획은 +x 쪽에 걸리니 회전만 하면 된다. 한 변이 몇 m 인지는 같은 폴더 `samjae.json` 의 `sizeMeters`. 다 그린 뒤 층들이 함께 덮는 쪽만 잘라 쓴다(V-10, 픽셀이 3분의 1로): json `crop`(512 칸에서 잘라 낸 [x, y, w, h], 너비·높이 4의 배수)과 `pivot`(잘린 그림에서 몸 위치). 셰이더는 `_Rect` 로 원래 칸 좌표를 되찾아 그어짐·흩어짐을 셈하고, WeaponRunner 는 사각형을 그 자리로 옮겨 줄인다(`brushCrops`). 미리보기는 `docs/vfx_preview/brush_samjae.png`(삼재검법)와 `brush_start9.png`(시작 무공 아홉).

## 절기 각성 연출

절기를 얻는 순간은 한 판에 한두 번뿐이라 화면 전체를 멈춰 세운다. 시간표와 규칙은 기획서 8장 '절기 그릇과 각성' 표가 기준이다.
시연: 웹 프로토타입 제목 화면 '절기 각성 보기', 또는 주소 끝 `#awaken` (https://bloodrain-proto.pages.dev/#awaken).

| 프로토타입에서 | Unity에서 |
|---|---|
| 연출 시계는 실제 시간, 세상은 0.04배 | `Time.timeScale` 0.04, 연출 코루틴·파티클·카메라는 `unscaledDeltaTime` |
| 흑백 + 깨어나는 사람 둘레만 색(구멍), 파동 때 구멍이 화면 끝까지 커지며 색이 돌아옴 | URP Fullscreen Pass 셰이더: 채도 0, `_Center`·`_Radius`, 가장자리 어둡게 |
| 화면 16% 확대 후 되돌림 | Cinemachine 카메라 Orthographic Size ×0.86, 언스케일 시간 |
| 흔들림 = 트라우마² × 부드러운 잡음, 0.03rad 기울기 | Cinemachine Impulse(언스케일) 또는 직접 구현. 설정 배율(100·50·0%) 곱하기 |
| 화면 끝 먹 알갱이 70개가 몸으로 빨려 듦 | 파티클 시스템, 언스케일, 끌어당김 힘 |
| 무공 칸 글자가 날아와 몸에 스밈 | HUD 아이콘 위치 → 월드 좌표로 포물선 트윈 |
| 금빛 균열(위아래, 지그재그) | 라인 렌더러 3겹(넓고 옅게 / 금 / 밝은 심), 지그재그 값은 미리 정함 |
| 한자 이름 한 글자씩 위→아래 붓질 | TextMeshPro + `_Reveal` 마스크 셰이더, 글자마다 0.11초 차. 가로 화면은 위에 가로, 세로 화면은 오른쪽에 세로 |
| 흰 물감 띠(겹친 붓 획 7개 + 마른 붓 자국) | 붓 획 텍스처 겹침, `_Progress` |
| 絶 낙관 1.8배 → 1배로 찍힘 | 낙관 텍스처 + TMP 글자, 스케일 커브 |
| 낙관 순간 0.08초 탁본 뒤집기 | 기존 뒤집기 패스 재사용. 움직임 줄이기 설정이면 건너뜀 |
| 먹 고리 파동 | 링 메시 + 셰이더. 판정(잡몹 처치, 정예 15%, 보스 4%, 적 탄 제거)은 Core |
| 여운: 금빛 기운 8초, 적 생성 2.5초 멈춤 | 파티클 + Core의 피해 배율·스폰 멈춤 |
| 소리 4겹(낮은 북 / 먹 튀는 소리 / 낙관 / 범종과 큰 북) | 오디오 믹서 스냅샷으로 배경음 낮추기, 각성 소리는 우선순위 최상 |

- 긴 연출 3.5초는 그 절기를 계정에서 처음 깨울 때, 그다음부터 짧은 연출 1.5초. 설정에서 바꿀 수 있다.
- 연출 동안 플레이어 무적, 레벨업 창과 보갑 줍기는 미룬다.
- 휴대폰 세로 화면에선 이름을 세로로 써야 글자가 커진다(가로로 쓰면 다섯 글자가 60px 안팎).
- 절기 이름 글꼴: Yuji Boku(SIL OFL). 절기 16개 이름의 번체 한자가 다 있다. Ma Shan Zheng은 劍·無·飛 같은 번체가 빠져 있어 쓰지 않는다.

## 아트 애셋 나눠 맡기

| 무엇 | 어떻게 | 왜 |
|---|---|---|
| 무공 이펙트 | 코드로 구운 텍스처(`bake_brush.py`) + ChatGPT 로 뽑은 재료 한 장(안개·번개·불꽃 결·꽃잎·진법 문양, `import_vfx_ai.py`) + 셰이더·파티클 | 텍스처 한 장은 붓질 한 순간이고 움직임은 셰이더가 만든다. AI 이미지는 여러 프레임을 한결같이 못 뽑으니 한 장씩만 쓴다(2026-11-01 사람: '셰이더와 아트를 함께 써서 최대한 예쁘게'). 생산 순서는 `art_pipeline.md` |
| 캐릭터·적·보스 원화 | ChatGPT 앱, 사람이 볼 때 소량. 같은 계열은 같은 대화방 | 그림 맛은 이미지 생성이 낫다 |
| 캐릭터 움직임 | 부위별로 잘라 뼈대 애니메이션(Unity 2D Animation), 강시 콩콩은 코드 | 프레임 그림을 여러 장 일관되게 뽑기가 어렵다 |
| 무공·심법 아이콘 | 서예 한자 + 먹 원(프로토타입 방식), 필요하면 원화 아이콘 | 세계관과 맞고 바로 만든다 |
| 바닥 타일 | 절차적 생성 + 소품만 AI | 이음새 없음 |
