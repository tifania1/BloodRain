# M4 그림 목록

M4 얼리 액세스 준비(기획서 17장: 화산·곤륜·십만대산과 종장, 문파 9)에 새로 들어갈 그림이다. M2 목록 `art_list.md` 와 같은 규칙을 따른다(규격·chat·우선·주홍 금지·글자 안 굽기). M2·M3 큐가 먼저 뽑히도록 이 줄들은 큐 맨 뒤에 넣었다.

- 외형은 기획서 5장 '인물 소개와 외형'에서 가져왔다. 화산·곤륜은 대표 인물이 없어(5장 '화산·곤륜 대표 인물(지금은 대표 인물 없이 문파만 있음)') 제자 남자 몸 시트가 그 문파 옷차림의 기준이다. 옷차림은 문파 시작 무공(5장 표: 화산 낙화검우, 곤륜 뇌부, 마교 혈조)과 문파 산문 카드(card_sect_*)에 맞춰 지었다. 뽑은 뒤 사람이 고른다.
- 백야의 '붉은 눈·붉게 변한 오른팔'은 주홍이 적 몫이라(12장 가독성) 하연의 두건처럼 '말라붙은 피 같은 검붉은 갈색 팔·흐린 녹슨 갈색 눈'으로 적었다. 반쯤 혈인이 된 티는 검은 핏줄로 낸다.
- 화산 매화 수는 옅은 분홍으로만 적었다(붉은 매화는 적 몫 색과 겹친다).
- 몸 성별은 후보마다 반반이고 소림만 남자라(21장, cheonha.json maleOnlySects) 세 문파 모두 남녀 몸 둘씩이다.
- 적·정예 옷차림은 기획서에 없어 같은 땅 문파·M3 적 문구 틀(회색 살갗에 붉은 핏줄, 이마 부적은 비움)에 맞춰 지었다. 적 쪽이라 주홍을 써도 된다.
- 땅의 주인 셋은 `docs/story/boss_cuts.md` 의 '만남 2' 칸, 혈마 단목현은 6장 종장 단계(혈의는 사람 모습, 진혈마는 하늘을 가린 형체)와 `docs/story/final.md`(의원이었다는 것만)에서 가져왔다. 혈해 단계는 바닥 피바다와 혈영이라 따로 그리지 않는다.
- 설무향 빙분신·빙혈의 제자 분신·혈영 분신 무공 모양은 Unity 가 같은 그림을 흐리게 하거나 얹는다.
- 아직 넣지 않은 것: 땅의 주인·종장 컷, 지형 소품·바닥, M4 무공 아이콘.
- 밤 이미지 세션은 하룻밤 30장 안쪽이라 M2·M3 남은 줄 다음에 이 40장까지 이틀 밤쯤 더 걸린다.
