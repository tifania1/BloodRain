# 문파 무공 늘리기 — 곤륜 다섯 설계안 (WS-04 앞당김)

2026-11-26 03시 밤 개발 세션이 씀. 소림(`sect_arts.md`, #59)·개방(#65)·남궁(#66)·당가(#71)·수로채(#72)·무당(#73)·화산(#74)과 같은 틀. **사람 확인 대기**(decisions #75). 소림 설계안의 공통 규칙(6단은 대표 무공에만, 자기 문파 무공 뽑기 무게 ×1.5, 다른 몸은 땅의 주인 해금)이 바뀌면 이 문서도 같이 바뀐다. 숫자는 전부 **추천값**이다.

## 다른 문파와 다른 점
- 곤륜 시너지 구성원에 공격 무공은 뇌부 하나뿐이다(`synergies.json` kunlun: 뇌부·도문심법·화룡심법). 그래서 **대표 + 새 넷**.
- 곤륜은 두 결이다: 도가 선문(부적·어검)과 설원(얼음). 지금 뇌부가 부적 쪽이라 새 넷을 부적 둘·얼음 둘로 나눴다.
- `sect_arts.md` 초안 넷 가운데 하나를 바꿨다.
  - '운룡낙(공중에서 내려찍기)'은 심법 '운룡보'와 이름이 겹치고, 개방 취팔선보·무당 초안 등운보와 같은 '뛰어올라 내려앉기' 쪽이라 '어검술(떠 있는 검이 차례로 찌름)'로 바꿨다.
  - 빙백장·설산검은 지금 방식(장풍 `slow_projectile`, 이화창 `pierce_thrust`)에 얼림 칸만 더한다. 새 판정이 둘뿐이라 일이 적다.
- 얼음 쪽 짝 심법이 곤륜에 없다(도문심법은 기연, 화룡심법은 불). **새 심법 하나(빙백심법)**를 소림 반야심공처럼 추천한다.
- 얼림 규칙은 오의 천설부(5장)와 같다: 일반 적은 다 얼고, 정예는 짧게, 땅의 주인은 안 언다.

## 새 넷 하나씩

### 빙백장 — 얼리는 장력 (`slow_projectile` + 얼림)
- 판정: 장풍과 같은 느린 장력(반경 0.55m, 9m). 맞은 일반 적 0.6초 얼림(제자리 멈춤, 얼어 있는 동안 넉백 안 받음), 정예 0.2초, 땅의 주인 안 언다. 관통은 장풍과 같다.
- 견준 것: 장풍(20→55 / 2.2초)보다 조금 약하고 느리다. 대신 얼림이 붙는다. 곤륜 고유 능력(3m 안 적 10% 느려짐)과 묶여 '다가오기 전에 멈춤'.
- 다섯 단계: 초식 먹 손바닥 → 경력 맞은 적 몸에 서리 먹점 → 기 문파 상징색(#24809A) 청록 담채 → 기인 얼림 풀릴 때 얼음 조각 흩어짐 → 강기 손바닥 뒤로 눈발 꼬리.

### 설산검 — 얼음 가시를 남기는 찌르기 (`pierce_thrust` + 얼음 가시)
- 판정: 이화창과 같은 앞 찌르기(4.2m, 폭 0.5m). 찌른 줄을 따라 얼음 가시가 1.5초 남고, 밟은 적 1초 40% 느려짐(정예 20%, 땅의 주인 안 걸림). Lv5 두 번 찌름(0.15초 사이).
- 견준 것: 이화창(22→55 / 1.6초)보다 조금 약하고 느리며 길 막기가 붙는다. 앞에서 몰려오는 줄(곤륜 설원 눈보라 길)에 맞는다.
- 다섯 단계: 초식 마른 먹 찌르기 → 경력 줄 끝 먹 튐 → 기 줄에 청록 담채 얼음 → 기인 가시가 부서질 때 눈가루 → 강기 줄이 눈 덮인 산등성이 꼴로 솟음.

### 진천부 — 내 둘레 부적 결계 (`seal_ward`, 새 방식)
- 판정: 쿨다운 7초마다 내 자리에 반경 2.6m 네모 결계(네 귀퉁이에 부적)를 깐다. 결계는 땅에 붙어 있고 나는 나갈 수 있다. 경계에 닿은 적은 0.5초마다 피해 + 넉백 5(바깥으로). 안에 든 적은 30% 느려짐. 땅의 주인은 경계에 안 막히고 피해만.
- 견준 것: 소림 범종공(몸에 붙음, 받는 피해 감소)·남궁 천검막(앞, 탄 지우기)과 다른 '자리' 방어 — 결계 안에 서 있으면 숨 돌릴 틈이 생기고, 나가면 그 자리를 버린다. 스스로 피해는 약하다(경계에 몰린 적 초당 ≈ 15 × 2 × 4.5 / 7 ≈ 19).
- 곤륜 6단 뇌정합일(낙인)과 따로 논다. 낙인 벼락이 결계 안 적에게 옮아가면 그대로 맞는다.
- 다섯 단계: 초식 먹 네모 줄과 부적 넷 → 경력 경계에 닿을 때 먹 튐 → 기 청록 담채 바닥 → 기인 부적이 바람에 펄럭이며 빛 줄 → 강기 결계 위로 옅은 팔괘 무늬(글자 없이 줄로만).

### 어검술 — 떠 있는 검이 차례로 찌름 (`guided_sword`, 새 방식)
- 판정: 몸 위(0.8m)에 검이 떠 있다가 0.6초마다 7m 안 적 하나를 골라(가장 가까운 적부터, 같은 적을 이어서 고르지 않음) 날아가 찌르고 돌아온다. 검이 여럿이면 서로 다른 적을 고른다. 넉백 1.5. Lv8 찌를 때 줄에 있는 적 둘까지 관통.
- 견준 것: 비도술(10→22 / 0.8초, 쫓는 비도)과 같은 '하나씩 꾸준히' 쪽. Lv8 검 셋 ≈ 3 × 20 / 0.6 ≈ 100 이 적 여럿에 나뉜다 — 한 적 초당 ≈ 33. 지금 16 의 가운데(31~32)에 맞췄다.
- 다섯 단계: 초식 먹 검 그림자 → 경력 찌른 자리 먹점 → 기 검 날에 청록 담채 → 기인 돌아오는 길에 가는 빛 꼬리 → 강기 떠 있는 검 둘레로 작은 부적 하나씩.

## 절기와 6단
- 절기(이름과 모양만):
  - 빙백천리: 장력이 지나간 길이 1.5초 얼음 길이 되어, 길 위 적이 다 언다.
  - 설산만장: 찌른 끝에서 얼음 기둥이 부채꼴로 다섯 솟는다.
  - 천강진세: 결계가 둘(내 자리와 1.5초 전 자리), 경계에 닿아 밀린 적이 다른 결계 경계에 또 닿으면 피해 ×2.
  - 만검귀종: 검 여섯이 몸 둘레를 돌다 한꺼번에 가장 센 적에게 모여 찌름.
- 6단은 뇌부에만(`sinbyeong.md` 뇌정합일). 곤륜 병기 벽력인(`gear.json`) 등급 보너스는 다섯 무공 모두에.

## 레벨업 풀에 들어오는 규칙
- 곤륜 몸: 새 넷이 처음부터.
- 다른 몸: 계정에서 설무향(곤륜 설원 땅의 주인)을 처음 잡은 뒤부터(`unlock: "boss:kunlun"` — 곤륜 몸 해금과 같은 토큰).
- 곤륜 시너지 구성원 셋 → 여덟(새 넷 + 빙백심법). 단계 문턱 그대로.

## 곤륜 한 생 밸런스에 끼치는 것 (데이터로 옮길 때 잴 것)
- 곤륜 몸 30판: 경지 시각이 지금과 ±10% 안인지, 설무향 처치 시각(기획서 6장 목표) 안인지.
- 얼림 셋(빙백장·설산검 가시 느려짐·천설부 오의)과 진천부 느려짐, 곤륜 고유 능력 느려짐이 겹쳐 적이 거의 안 닿는 빌드가 되는지. 받는 접촉 피해가 지금 가장 단단한 빌드보다 15% 넘게 줄면 빙백장 얼림 0.6 → 0.4초.
- 설원 눈보라(보이는 범위 0.6배)에서 청록 담채 이펙트가 흰 눈에 묻히지 않는지 — 화면 쪽에서 볼 것.
