# 기획서 사본(gdd.md) 바뀐 곳

예약 세션이 `gdd.md` 를 고치면 여기에 한 줄씩 남긴다. 대화 세션이 원본 문서(Claude Docs)에 옮기고 줄 끝에 `→ 원본 반영` 을 붙인다.

형식: `- 날짜 · 장/절 · 무엇을(바꾼 문장이나 표 칸)`

- 2026-10-29 · 1·2·3·4·5·6·7·8·10·11·12·15·17·19·20·21장 · 천하 구조로 다시 씀(대화 세션). → 원본 반영 예정
- 2026-10-29 · 21장/환혼: 다음 몸 고르기 · '해금한 문파가 셋보다 적으면' → '해금한 문파가 후보 수보다 적으면(넷째 몸을 샀는데 문파가 셋만 열렸을 때)'. 처음부터 셋이 열려 있어 넷째 몸일 때만 생기는 일이라 고침(T-06)
