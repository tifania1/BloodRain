# 효과음 목록 (M2)

기획서 14장 '효과음'·'동시 재생 제한', 8장 각성 연출 '소리' 칸, 7장 돌파 연출, 8장 '피격과 사망'에서 M2 범위(17장: 서장과 숭산 일대, 문파 소림·개방·남궁, 원각, 침방·연무장·정산)에 실제로 울릴 소리를 사건마다 한 줄로 옮겼다.
어디서 구할지는 backlog BGM-08(사람 결정 대기). 배경음은 `audio_pipeline.md`.

- `id` 는 Unity 에서 부를 이름이다. 파일이 생기면 `Assets/Audio/SFX/<id>.ogg` 로 둔다.
- '근거'가 기획서에 없고 이 목록에서 처음 적은 줄은 맨 아래 '기획서에 없는 것'에 따로 모았다. 그 줄은 사람이 보고 넣거나 뺀다.

## 공통 규칙 (14장 '동시 재생 제한')

- 같은 효과음은 0.05초 안에 최대 4개만 재생한다.
- 진기 흡수음은 한 프레임에 하나로 합친다.

## 기획서에 없는 것 (사람이 보고 넣거나 뺀다)

아래는 M2 에서 화면에 일어나는데 기획서에 소리가 적혀 있지 않은 사건이다. 소리를 넣을지, 넣으면 무엇으로 할지 정해지기 전에는 만들지 않는다.

| 사건 | 근거 |
|---|---|
| 플레이어가 맞을 때 | 8장 '피격과 사망'(화면 표현만 있음) |
| 경공(대시) | 8장 '조작' |
| 오의를 쓸 때(목소리 기합 말고 효과음) | 14장 '목소리'는 기합만 |
| 우물 회복, 수레·장독·술독·검각 시렁 부수기 | 7장 '지형 기믹' 청운진·개방 총타·남궁세가 |
| 원각 패턴: 금강장 충격파, 십팔나한진, 범종 낙하, 30% 빛줄기 | 6장 땅의 주인 표(범종 낙하는 위 범종 소리를 쓸 수 있음) |
| 장삼 패턴: 포승줄, 호루라기, 내려찍기 | 6장 |
| 레벨업 카드 고르기·버튼·족자 펼침 같은 UI 소리 | 12장 UI(소리 없음) |
| 객잔·침방·연무장 화면의 바탕 소리(빗소리 말고) | 10장 |
