# 웹 두 판 — 1장 프로토타입과 천하 시안

2026-11-05 09:01 사람: "서장부터 원각까지 버전과 천하 시안 버전이 UI도 다르고 사용하는 용어도 좀 다르고 시야각도 좀 다른 느낌인데 둘이 아예 다른 버전인 것 같아."

맞다. 둘은 처음부터 다른 목적으로 따로 만든 파일이고, 지금도 코드를 나눠 쓰지 않는다. 대화 세션이 두 파일과 자동 점검 화면(`node tools/web_autocheck.js --shots`)을 견줘 본 것을 적는다.

## 어떻게 할지 (사람 결정 대기 WP-10)

**추천: 하나로 합친다. 1장 프로토타입을 바탕으로 하고, 천하 시안의 세상(축척 시야·지역·장막·땅의 주인·환혼·정산·침방·연무장)을 옮겨 붙인다.**

- 프로토타입 쪽 전투·HUD·레벨업이 기획서 8·12장과 더 가깝고, 사람이 손맛을 보는 판이 이쪽이다.
- 시안 쪽은 세상 규칙(7·10·21장)이 맞다. 그 규칙은 Core 와 데이터에 이미 있으니 그림·흐름만 옮기면 된다.
- 다 옮긴 뒤 시안은 '천하 지도 보기' 같은 확인용으로만 남기거나 닫는다.
- UI 개선안(`ui_benchmark.md`)은 합친 판에만 넣는다. 두 판에 따로 넣으면 또 갈라진다.
- 용어는 `glossary.md` 와 `Resources/Data/strings/ko.json` 의 키를 두 화면이 같이 읽게 해서 다시 갈라지지 않게 한다.

다른 안:
1. 시안을 바탕으로 프로토타입 전투를 옮긴다. 세상 쪽 코드가 더 크고 새것이지만, 전투·HUD·각성 연출을 다시 붙여야 해서 일이 더 많다(추정).
2. 웹은 지금에서 멈추고 Unity WebGL 빌드를 플레이 판으로 쓴다. Unity 에 한 생 고리가 생겼지만(LF-01~03) 아직 그림·UI가 비어 있고, 배포에 사람 몫 비밀값(C-11)이 필요하고, PC 빌드가 13분 넘게 걸린다. M1 끝 무렵이 맞다(추정).

합치기로 하면 클라우드 세션 몫으로 대략 이렇게 쪼갠다(backlog 에 넣는 것은 정해진 뒤).
1. 두 판이 같이 쓸 용어·HUD 문구를 한 곳에서 읽게
2. 프로토타입에 축척 시야와 지역 바닥·장막
