# 지형 기믹 시작값 안 (사람 결정 대기: R-10 · R4-07)

2026-11-05 평일 밤 클라우드 세션이 만든 **안**이다. 기획서 7장 '지형 기믹 수치'에 아직 없는 기믹 다섯(대나무 덤불·떠내려오는 배·역류 파도·운해·잔도)의 수치와, 기믹을 지역 안 어디에 몇 개 놓는지를 7장 표 꼴로 적었다. `decisions.md` 13·19번이 '클라우드가 시작값 표를 올리고 사람이 본다'를 추천했는데, 이 표가 그 표다. 사람이 '이대로'라고 하기 전엔 gimmicks.json·기획서·Core 에 넣지 않는다.

숫자는 새로 지어내지 않고 같은 땅이나 같은 모양의 기존 값에서 가져왔다. 칸 '가져온 곳'이 그 근거다. 길이는 지금 7장과 같이 화면 기준 m이고, 세상에 놓을 때 그 기믹이 생긴 경지의 축척을 곱한다.

## 2. 몇 개를 어디에 놓나

지역 안이 어디까지인지는 지금처럼 '그 자리에서 가장 가까운 지역'으로 본다(Core `Regions`, 웹 `nearestTwo`). 격자는 지역 한가운데를 원점으로 깔고, 그 칸에서 가장 가까운 지역이 그 기믹 땅일 때만 놓는다. 경지가 바뀌면 그 경지 축척으로 격자를 새로 깐다(기믹은 '지금 경지 축척으로 생긴다', 7장).

웹 천하 시안(`web/lookdev/cheonha.html` `LD`)이 이미 놀이판 값으로 놓고 있는 것은 그 값을 그대로 올렸다. 해 보고 어색했다는 기록은 없다.

## 3. 다른 안

- 대나무 덤불을 베이지 않는 탑림 그대로 두고, 음식은 등롱에서만. 8장 드롭 표 '대나무 덤불'을 지운다.
- 운해를 '숨기' 대신 '보이는 범위 0.7배'(눈보라 꼴)로. 숨기는 적 인공지능에 '놓침' 상태가 새로 들어가 Unity 일이 크다.
- 혈제단 넷을 고정 자리 대신 독안개처럼 켜질 때 플레이어 둘레(화면 대각선 0.4배)에. 경지가 올라도 제단이 늘 화면 근처에 있다.
- 잔도를 따로 두지 않고 화산은 낙석·매화 더미만. 17장 '밀릴 때 줄일 것'에 가까운 안.

## 4. 정해지면

1. gimmicks.json 에 `bambooThicket`·`driftingBoats`·`reverseWave`·`cloudSea`·`cliffPath`(cheonha id `cliff_path`) 과 배치 값(`layout` 묶음)을 넣고, 7장 '지형 기믹 수치' 표와 '아직 수치가 없습니다' 문장을 고친다. `gdd_changes.md` 한 줄.
2. Core `World/Gimmicks` 에 판정·배치 함수(탑림 `Layout` 꼴)와 테스트. 수치 표 테스트(`Gimmicks2Tests.수치_표가_데이터와_같다` 꼴)에 다섯 줄.
3. 웹 천하 시안 `LD` 의 놀이판 값을 gimmicks.json 에서 읽게 바꾼다.
4. unity_tasks R-13U·R4-13b 의 '먼저:' 를 푼다.
