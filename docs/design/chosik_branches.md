# 초식 갈래 설계안 (GU-05, 2026-11-24 밤 개발 세션)

roguelike_benchmark 안 ②: 무공 Lv7 에서 초식 둘 중 하나를 고른다. 먼저 삼재검법·나한권·취선봉·창천검기 넷.
사람은 2026-11-13 '추천 순서대로 전부'로 방향을 정했지만, 새 초식 넷의 이름과 숫자는 벤치마크에 '일섬' 예 하나뿐이라 아래는 **추천값**이다. 사람 확인 대기: decisions #62.

## 공통 규칙(추천)
- Lv7 레벨업 카드가 그 무공이면 카드 대신 갈래 카드 둘이 뜬다(가 — 지금 초식 / 나 — 새 초식). 고르면 그 생 끝까지 그대로.
- 가는 지금 데이터 그대로(삼재검법은 milestones 7 '3연 베기' 자리). 나는 Lv7·Lv8 에서 가의 값을 덮어쓰는 몇 칸만 가진다(데이터 `branches`).
- 둘째 초식의 잠금(안 ③ 성취의 소성으로 연다)은 GU-06 이 들어올 때 붙인다. 그 전까지는 둘 다 열려 있다.
- 절기는 어느 갈래든 그대로 깨어난다(절기 모양이 따로 있으니). 6단도 같다.
- 숫자는 '가'와 한 판 화력이 비슷하게(단일 대상 0.8~1.0배, 무리 상대는 가가 낫거나 나가 낫거나 하나씩). 시뮬레이터 `--synergy`·level-curve 로 다시 본다.

## 데이터 모양(추천)
`weapons.json` 무공에 `branches` 한 칸:

```json
"branches": { "level": 7, "options": [
  { "id": "samjae_triple", "nameKo": "3연 베기" },
  { "id": "samjae_ilseom", "nameKo": "일섬", "hanja": "一閃", "hits": 1, "rangeMul": 1.5, "damageMul": 2.6, "knockback": 6 }
] }
```

첫째 option 은 늘 '가'(덮어쓰기 없음). strings 키는 `weapon.<id>.branch.<option id>.name`·`.desc`. Core 는 `Loadout` 이 고른 갈래를 들고, WeaponRunner·시뮬레이터 `WeaponModel` 이 덮어쓰기를 곱한다.

## 숭산 한 생에 끼치는 것
- Lv7 은 숭산 한 생에서 시작 무공이 12~15분쯤 닿는다(level-curve). 고르는 카드가 한 번 더 생길 뿐 레벨업 수는 그대로다.
- 단일 대상이 0.87~1.0배라 땅의 주인 처치 시간은 거의 그대로, 무리 상대는 나한권 붕권·취선봉 쓸기가 조금 낫고 삼재 일섬·창천일검은 줄지은 적에 낫다.
