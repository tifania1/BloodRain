## 묶기와 올리기

```
python tools/build_web_prototype.py              # site/ 에 공개용 문서 + 링크 미리보기 이미지(og.jpg)
python tools/build_web_prototype.py --artifact   # .artifact/ 에 아티팩트용 본문도
python tools/deploy_web_prototype.py             # PC에서 묶어서 정식 주소로 올리기(wrangler 로그인 필요)
python tools/deploy_web_prototype.py --branch claude/dev   # 미리보기 주소로(claude-dev 라고 쓰면 주소 뒤에 글자가 붙는다)
```

- 데이터 JSON이나 `template.html` 이 바뀌어 `main`·`claude/dev` 에 푸시되면 `.github/workflows/web-prototype.yml` 이 묶어서 올린다.
  올리기에는 저장소 비밀값 `CLOUDFLARE_API_TOKEN`·`CLOUDFLARE_ACCOUNT_ID` 가 있어야 한다(WebGL 배포와 같은 값). 없으면 묶기만 확인하고 넘어간다.
- 비밀값이 없는 동안은 PC에서 `deploy_web_prototype.py` 로 올린다. PC의 wrangler 로그인을 그대로 써서 키를 따로 만들 필요가 없다.
- 아티팩트를 다시 올릴 때는 위 아티팩트 주소에 덮어쓴다(새로 올리면 주소가 바뀐다).
- 공개용 문서는 `<!doctype>`·charset·휴대폰 viewport·링크 미리보기(og) 태그를 붙인 완전한 HTML이고, 아티팩트용은 그 뼈대가 없는 본문이다.

## 프로토타입에서만 쓰는 값

기획서와 데이터에 아직 없는 값이다. 해 보고 쓰기로 하면 `balance.json`·`enemies.json`·기획서로 옮긴다. `template.html` 맨 위 상수에 모여 있다.

| 값 | 지금 | 왜 |
|---|---|---|
| 맞은 뒤 무적 `HIT_IFRAMES` | 0.5초 | 없으면 강시 두세 마리에 닿기만 해도 초당 30 넘게 깎여 첫 1분을 못 넘겼다 |
| 강시 뛰는 비율 `HOP_DUTY` | 0.6초 중 72% | 55%면 뛰는 순간 속도가 혈강시 기준 초속 7m로 플레이어(4.6m)보다 빨라 피할 수가 없었다. 평균 속도는 데이터 그대로 |
| 처치 진기 | 시강·혈인 1, 혈강시 2, 혈무사 3, 목인나한 3, 동갑시 4, 정예 25 | `enemies.json` 에 진기 값이 없다 |
| 원각 체력 `BOSS_HP` | 정식 20,000 / 빠른 12,000 | 기획서 90,000은 초당 1,500을 가정. 프로토타입 무공으론 너무 길다 |
| 보스전 잡몹 수 `BOSS_TRASH` | 60 | 120이면 무공이 잡몹에 다 맞아 보스가 안 깎였다 |

또 하나, 삼재검법은 사거리 안에 적이 있으면 가장 가까운 적 쪽으로 벤다(기획서는 '바라보는 방향'). 도망치며 싸우는 장르라 바라보는 방향으로만 베면 뒤에서 쫓아오는 적을 거의 못 맞혔다.

## 자동 판으로 숫자 보기

페이지 콘솔에서 `__hyeolu.sim('full', 1300)` 을 부르면 자동 조종으로 한 판을 빨리 돌리고 1분마다 레벨·처치·기혈을 돌려준다. 결과의 `evo` 에 절기가 깨어난 시각·레벨·계기가 남는다. 넷째 인자로 매 걸음 불릴 함수를 줄 수 있다. 자동 조종은 사람보다 서툴다(가까운 적과 거리를 두고 돌기만 한다).
2026-10-28에 돌려 본 결과:

- 5분 Lv15 안팎으로 기획서 목표와 맞는다.
- 보통 난이도에서 자동 판은 대개 3~10분에 쓰러진다. 잘 풀린 판은 원각까지 잡는데 20분에 Lv75~100이라 목표(Lv60)를 넘는다. 강한 빌드가 적을 빨리 지우면 스폰이 `spawnFractionPerSecond` 만큼 바로 채워져 처치 수가 크게 늘기 때문이다. B-07 시뮬레이션에서 같이 볼 것.
- 데스크톱 헤드리스 크롬에서 적 220마리일 때 56fps.

절기 그릇 규칙으로 바꾼 뒤 달라진 점(기획서 목표 레벨 기준):

| | 예전(일류 + 보갑) | 그릇 규칙 |
|---|---|---|
| 첫 절기가 가장 빨리 나오는 때 | 10분 보갑(일류는 7분) | 절정 돌파, 약 11분 반 |
| 보스 전에 쓸 수 있는 절기 | 10·15분 보갑에서 둘(7장은 혈제단 보갑으로 더) | 둘(절정·초절정). 보갑이 많아도 늘지 않는다 |
| 짝 심법 | 아무 레벨 | Lv3 이상 |
| 셋째 절기 | 보스 보갑(보스를 잡은 뒤) | 화경(Lv70) 빌드만 |

자동 판(빠른 판 10번씩, 보통·편하게, 짝 심법을 먼저 올리는 조종 포함)으로는 두 규칙 차이가 잘 드러나지 않았다. 자동 조종이 대개 15분 전에 쓰러지고, 원각까지 간 판은 20분에 Lv80 안팎이라 목표(Lv60)보다 높아 그릇 셋을 채운다. 레벨이 높게 나오는 건 B-07에서 같이 본다.

## 천하 시안

`web/lookdev/cheonha.html` 은 천하 구조(기획서 5·7·10·21장)를 손으로 만져 보는 놀이판이다. 무공은 검기·도는 검·먹 파동 셋이 경지에 따라 저절로 붙고, 레벨 셋마다 레벨업 카드 석 장 중 하나를 고른다(T-21). 카드는 이 세 무공의 단계(검기 피해 +12%, 도는 검 +1자루, 먹 파동 간격 -8%, 각 8단계까지)와 몸에 바로 붙는 능력치만 쓰는 심법(passives.json 에서 청명·금강·뇌정·양의·청심·운룡·매화 일곱, 5단계까지. 흡혈·투사체 속도처럼 이 시안에 없는 효과가 섞인 심법은 뺐다)이다. 땅의 주인은 `bosspatterns.json` 시간표대로 패턴을 쓴다. 땅의 주인 아홉의 패턴 모양을 다 그린다(아래 '지역 콘텐츠'·'화산·곤륜 설원·십만대산 땅의 주인'). 길이는 싸움을 건 경지 축척을 곱하고, 피해는 패턴 피해 ÷ 몸 피해 × 이 시안의 보스 몸 피해다.

원본에 데이터 자리(`/*__DATA__*/null`)가 있고, 빌드가 `cheonha.json` 전체, characters·weapons 이름, enemies.json 땅의 주인(이름·기준 체력), balance.json 의 `realms`·`xpCurve`·`training`·`stats`·`spawnTarget`·`dash`·`limits`·`yinyang`·`drops`, insights.json 전체를 끼워 넣는다(`tools/build_web_prototype.py` 의 `cheonha_blob`). 원본 파일을 그냥 열면 빌드하라는 문구만 나온다. 데이터를 바꾸면 빌드만 다시 돌리면 된다.

### 데이터에서 그대로 읽는 것

- 문파 아홉: 이름, 태어나는 곳, 시작 무공, 대표 인물, 기혈·걸음. 처음엔 `unlock: "start"` 인 소림·개방·남궁만 열려 있고, 그 땅의 주인을 처음 쓰러뜨리면 `boss:<지역>` 문파가 열린다.
- 환생 후보 셋(21장): 열린 문파에서 겹치지 않게, 성질 0·1·2개를 20·60·20%로, `excludes` 쌍은 같이 안 붙는다. 첫 환혼은 소림·개방·남궁 고정에 성질 없음. 카드에는 태어나는 곳과 혈운 농도(빗금 굵기), 시작 무공, 기혈·걸음, 대표 인물, 성질과 효과가 나온다. 숫자키 1~3으로도 고른다.
- 몸: 문파 기혈·걸음 × (1 + 연무장 + 성질). 놀이판에 실제로 들어가는 성질 효과는 공력·기혈·신법·회복·흡기·쾌속·심득·경공 충전·호신·음식 회복(정예 구슬 회복)과 음양 시작(게이지 시작값)이다. 기연·탐욕은 카드에 흐리게만 보인다.
- 돌파 깨달음(RM-07, 기획서 3장·5장): balance.json `realms` 보상에 `insight_choice` 가 붙은 경지(이류~화경 다섯)를 돌파하면, 연출이 끝난 뒤 레벨업 카드보다 먼저 깨달음 석 장(insights.json `choices.base`)이 뜬다. 뽑는 규칙은 Core `Insights.Roll` 과 같다(이번 생에 가진 것 빼고 겹치지 않게). 문파 몸에는 진소운 특성(넉 장)이 없어 늘 석 장이고 보통 깨달음 일곱 중에서 뽑는다. 마교 몸은 cheonha.json `bloodArt.demonicInsightsPerBreakthrough`(1) 자리를 마공 넷에서 먼저 뽑는다(`RollWithDemonic`). 효과는 Core `InsightEffects` 와 같다. 일검파만(+40%)·이기어검(+50%, 검기가 `front_arc` 라 걸림)은 이 시안의 첫 무공인 검기에만, 운기조식(5초 멈추면 초당 2%, 경공·끌려감은 움직임), 금종조(10초마다 한 대를 없던 일로, 묶임·끌림도 없음. 준비되면 몸에 금빛 점선 테), 천리추종(흡기 2배), 역근(게이지 0, 이후 심법 카드 기울기 절반, 남는 소수는 다음에), 살기충천(고른 뒤 처치 100마다 공력 +1%, 최대 30%), 혈해공(공력 +30%·기혈 -20%), 혈광폭주(기혈 50% 아래면 쾌속 +25%·받는 피해 +15%). 흡혈대법(흡혈이 없음)·심마환영(혈공이 없음)은 카드에 흐리게 나오고 골라도 아무것도 안 붙는다. 자동 판은 첫 장을 고른다. 멈춤 화면에 가진 깨달음이 나온다.
- 한 번 깨친 길(RM-11, 21장, cheonha.json `mastery`): 계정에서 이미 오른 경지(`cheonha_meta2` 의 `reached`)로 다시 돌파하면 Core `Soul.Breakthrough`·`Breakthrough.Start` 처럼 같은 연출을 `breakthrough.revisitSeconds`(0.7초)로 줄이고(연출 시계가 1.4 ÷ 0.7 = 2배로 감, 생성 멈춤·쓸림·글자도 같이), 깨달음 후보가 `revisitInsightChoicesBonus`(1)장 늘어 넉 장이다. 돌파 글자 아래가 '세상이 물러난다' 대신 '한 번 깨친 길'. 처음 오른 경지는 지금 연출 그대로이고 윤회의 기 100 은 원래 있던 대로다.
- 경지 문턱(Lv10·20·35·50·70·90)과 진기 곡선, 축척(한 단계 2.25배, 삼류 대각선 36m, 경지 안 0.35몫, 장막 2.4배, 현경부터 장막 없음), 덩이 사람 수(1·4·9·16·28·44·64, 남은 기혈만큼 줄여 그림, 처치 수는 사람 수로), 밟힘 진기 0.3, 돌파 연출 시각(세상 0.05배, 0.2~1.4초 물러남, 0.8초에 대각선 0.6배 안 쓸림).
- 혈운 농도: 가장 가까운 두 지역 섞기. 적은 생긴 자리의 농도로 기혈 × 농도, 피해 × √농도(11장 식). 화면 빗줄기는 지금 선 자리 농도만큼 굵고 많아지고, HUD 위 가운데에 지역 이름과 농도, 멀리 본 지도에는 지명 옆 빗금으로 보인다.
- 땅의 주인: 절정부터 장막 안 보스 지역이 깨어나 혈운 기둥과 화면 끝 붉은 표시가 뜬다. 장막이 넓어지면 새로 들어온 곳도 깨어난다. 지역 한가운데(화면 대각선 × cheonha.json `engageViewMultiple`, 지금 0.15배)에 들어서면 1.2초 경고 뒤 싸움이고(Core 의 5초 경고는 깨어날 때 이미 원 안인 경우만이라, 시안은 아래 '들어서면' 규칙으로 대신한다), 그동안 생성 목표가 0.4배다. 기혈 = 기준 체력 × (1 + 0.08 × 환산 분) ÷ 2.6 × 0.15. 첫 처치면 봉인석·문파 해금·윤회의 기 300, 다시 잡으면 100. 봉인석 일곱이면 봉마곡이 지도에 나타나고 현경에서 혈마가 깨어나며, 종장(아래 '종장')을 다 넘기면 '봉인'으로 생이 끝난다. 그림은 모두 혈마 한 장이다.
- 윤회의 기 정산(10장): (1 + 둔재·단명 보너스) × (0.04 × Σ(구슬 값 × 주운 자리 농도) + 땅의 주인 + 처음 밟은 땅 50 + 처음 오른 경지 100). 정산 화면에 줄마다 내역이 나온다. 구슬 값은 심득을 곱하기 전 값이다.
- 연무장(RM-09): balance.json `training` 스무 항목 가운데 이 시안의 몸에 실제로 들어가는 열(공력·기혈·호신·회복·쾌속·범위·신법·흡기·심득·경공 충전, 데이터 순서). 투사체 속도·지속·투사체 수·기연·탐욕·절기 충전·부활·카드 다시 굴리기/봉인/넘기기는 받을 곳이 없어 뺐다. 비용 = 기본가 × 다음 레벨 × (1 + 0.1 × 지금까지 산 총 레벨). 언제든 모두 돌려받을 수 있다. 쾌속처럼 2.5% 단위인 값은 소수 한 자리까지 쓴다.

- 서장 정산(WP-02, Core `Soul.EndLife` 가 서장 생을 받는 것과 같게): 웹 서장에서 넘어오면 정산 식 그대로 0.04 × 주운 구슬 값 × 청운진 농도 0.8 + 청운진 처음 밟음 50 + 서장에서 처음 오른 경지(보통 이류·일류) 100씩을 윤회의 기로 넣고, 청운진을 밟은 땅, 그 경지를 오른 경지로 남긴다. 그래서 첫 문파 생의 이류·일류 돌파는 '한 번 깨친 길'(연출 2배 빠름, 깨달음 넉 장)이고 절정부터 처음 연출이다. 첫 생 시작에 '서장 · 윤회의 기 +N' 알림. 서장은 한 번뿐이라 `cheonha_meta2` 의 `prologue` 가 있으면 다시 셈하지 않는다. 자동 판 서장(Lv28~29, 구슬 3,800~4,200)이면 370~390. 시안의 '윤회 N번'(meta.lives)은 문파 몸으로 산 생만 센다(Core `Soul.Lives` 는 서장까지 센다). 서장을 거치지 않고 시안을 바로 열면 서장 정산 없이 예전처럼 시작한다.
- 한 생 사건(RM-14, 7장 '한 생의 시간대별 흐름', chapters.json `life.events`): 환산 분(레벨 ÷ 3)이 사건 시각에 닿으면 차례로 일어난다. 돌파 연출·땅의 주인 싸움 중이면 끝날 때까지 미룬다. 혈인 돌진(3.5·8.5·9.5·15.5·16.6·17.7·21.5·24.5분, 14~40)은 화면 대각선 0.6배 밖 한쪽에서 1.2m × 축척 간격 한 줄 벽으로 곧게 달려오고 어딘가 두 칸이 빈다(1장 프로토타입과 같은 꼴). 혈인은 `lifeSeconds`(14초) 뒤 사라지고 되돌려 놓지 않는다. 6.5분 무리 10은 서 있는 지역 고유 적 가운데 하나(Core `RegionSpawns.EnemyFor` 처럼 난수 한 번, 숭산이면 목인나한)를 한 무더기로, 고유 적이 없는 땅이면 혈강시. 금선지네·쌍강시처럼 한 번에 여럿 나오는 적은 열 명을 넘길 때까지 내서 금선지네는 두 줄(16)이 된다. 13.5분 동갑시 포위 24는 화면 대각선 0.6배 원 위에 고르게. 적 값은 enemies.json 을 고유 적과 같은 기준(`localHpRef` 등)으로 바꾼다. 금두꺼비·보부상·은빛 등롱은 은자가 시안에 없어 뺐다.

### 놀이판에서만 쓰는 값

`cheonha.html` 맨 위 `LD` 에 모여 있고, 콘솔에서 `__ch.tune({...})` 로 바꿔 볼 수 있다. 시간은 자동 조종으로 소림에서 태어나 돌린 값이다.

| 값 | 지금 | 왜 |
|---|---|---|
| `cardEvery` | 3 | 레벨업 카드를 레벨 셋마다 한 장. 이 시안은 레벨이 1장 프로토타입보다 세 배쯤 빨리 올라 매 레벨이면 몇 초마다 화면이 멈춘다 |
| `killsPerLevel` | 14 | 덩이 하나의 진기 구슬 값 = 그 덩이가 생긴 레벨의 필요 진기 ÷ 14. 화면 위 적이 기획서보다 훨씬 적어서 구슬 하나를 크게 잡았다. 보통 속도로 이류 2분, 절정 4분 40초, 현경 9분. 구슬 값의 합이 오른 레벨의 누적 진기와 거의 같아서, 윤회의 기는 기획서 목표(농도 1에서 레벨 30 약 170, 레벨 90 약 2,000)를 따라간다 |
| `fastXp` | 3 | '빨리 훑어보기' 진기 배율. 현경까지 약 4분. 같은 레벨까지 오르면 윤회의 기는 보통 속도와 같다 |
| `minPerLevel` | 1/3 | 환산 분 = 레벨 ÷ 3(7장 평균 도달: 레벨 35 = 11분 40초). 땅의 주인 기혈의 '경과 분'과 생성 목표에 쓴다 |
| 생성 목표 | 24 + 0.25 × balance.json 목표(환산 분) | 생성 중지 시각(19분) 뒤로는 400을 지킨다(11장). 목표 덩이 수는 최대 124 |

| `eliteEvery` | 24초 | 정예: 기혈 10배, 진기 6배, 기혈 25 회복 구슬 |
| `power` | 2.4 | 경지 한 단계마다 내 피해와 적 기혈이 같이 2.4배. 무공 고르기가 없는 대신 |
| `bossHpScale` | 0.15 | 절정 무렵(환산 11분 40초) 원각 약 20초, 마천패 40~55초 |
| `baseRegen` | 초당 0.2 | 기획서 기본 회복은 0. 없으면 자동 판이 4분을 못 버텼다 |

흡기는 balance.json 의 1.5m 그대로다. 자동 조종이 구슬을 주우러 다니게 고쳤다.

### 기획서와 다르게 읽은 곳

- 땅의 주인 '들어서면': 깨어나는 순간이나 돌파로 원이 넓어지는 순간 이미 원 안에 서 있었다면, 그때 거리의 0.6배(최소 대각선 0.12배)까지 기둥 쪽으로 다가서야 싸움이 붙는다. 소림처럼 보스 지역에서 태어나면 절정 돌파 순간 한가운데에 서 있고, 화경·현경에선 원이 수백 m라 글자 그대로 두면 돌파하자마자 싸움이 줄줄이 붙었다.
- 처음 오른 경지 보너스는 이류~현경 여섯 번만 센다. 삼류는 태어날 때부터라 '오른' 것이 아니라고 봤다.
- 봉마곡은 봉인석 일곱 전엔 혈운 농도 섞기에서도 뺀다(지도 한가운데라 넣으면 숭산·무당 사이가 짙어진다).
- 구슬의 '그 자리 혈운 농도'는 주운 자리 값이다.
- 혈마를 쓰러뜨려도 윤회의 기 보너스는 없다(10장 표에 없음).
- 은자가 없어서 '남은 은자 절반'은 빠졌다. 혈정은 RM-13 부터 있다(아래 '정산 화면').
- 지형 기믹은 독안개·물·태극 바닥·범종·탑림 다섯(아래 '지역 콘텐츠'·'숭산 기믹').

### 지역 콘텐츠(WP-01, 2026-11-04)

당가타·장강·무당산(M3)이 데이터대로 돈다. 1장 프로토타입(`template.html`)은 숭산 한 판이라 그대로 두고, 세 지역은 천하 시안에서만 본다.

- 고유 적(enemies.json 에서 `chapter` 가 있는 적): 서 있는 지역의 것을 chapters.json 한 생 `localShare`(환산 5분부터 10%, 15분부터 15%) 확률로 낸다. 독두꺼비(죽으면 독 웅덩이)·금선지네(여덟 마디가 한 줄로)·독인(둘레 독 기운), 수귀(물에서만 나오고 물속에서 끌어당김)·수적(갈고리로 0.8초 묶음), 흑백 쌍강시(짝이 살아 있으면 10초 뒤 반 기혈로 일어남). 목인나한(RM-12)은 쓰러지면 나뭇조각이 터져 반경 2.5m × 경지 축척 안의 다른 적(땅의 주인 빼고)과 플레이어에게 한 번 피해를 준다. 기획서 값 40·6 은 이 시안 단위로 바꿔 쓴다: 적 몫은 목인나한 기혈에 대한 비율(40 ÷ 120, 제 기혈의 3분의 1), 플레이어 몫은 독 웅덩이처럼 접촉 피해에 대한 비율(6 ÷ 10). 옆 목인나한이 같이 쓰러지면 잇따라 터진다. 화산·곤륜·십만대산 고유 적은 기혈·걸음·피해만 들어가고 제 동작은 없다.
- 정예: 한 생 정예 사건(5·10·15·20·25분, 환산 분)마다 서 있는 지역의 장 표(enemies.json `elites`)에서 n번째. 표가 없거나 청운진·개방 총타·남궁세가면 숭산 표(`eliteFallback`). 패턴은 bosspatterns.json `elites` 그대로(독 장판 연쇄·비도 부채꼴·독안개 확장·갈고리 3연·수귀 부르기·방패 돌진·쌍강 내려찍기·검진·큰 피 웅덩이, 숭산 셋도). 이 시안의 이름 없는 정예(24초마다 쫓아오기만)는 따로 그대로 있다. 화산·곤륜·십만대산 정예는 bosspatterns.json 에 패턴이 아직 없어 쫓아오기만 한다.
- 땅의 주인: 당소혜·마천패·혈허진인 패턴이 다 나온다. 판정은 Core `BossPatterns`(R-11)와 같은 셈이다(R-11w, `BossFieldRulesTests.웹_천하_시안이_Core_와_같은_셈을_쓴다`). 반쪽 독안개(보스를 지나는 세로줄, 처음엔 플레이어 쪽 그다음 번갈아)·부채꼴 암기 3연·금선지네 소환·분열(셋이 남은 기혈을 나눠 갖고, 첫 몸이 누운 뒤 4초 안에 다 못 잡으면 누운 몸이 남은 몸 가운데 가장 많은 기혈로 일어남. 그동안 패턴은 멈춤), 갈고리 사슬(끌려감)·물기둥·수귀 소환·역류 파도(화면을 쓸고 가는 붉은 물결, 경공으로 넘음), 흑백(예고 때 플레이어 쪽이 검은 구역, 음양 게이지가 기운 쪽이 내 색이고 아닌 구역에서 받는 피해 2배, 태극 구간이면 안전)·태극권(기본 이동속도 절반으로 들이쉬고 터짐, 경공 중엔 안 끌림)·칠성검진(플레이어를 국자 끝에, 손잡이를 보스 쪽에)·흑백 경계(돎).
- 지형 기믹(gimmicks.json): 독안개(당가타, 한 생 90초마다 내 둘레에서 퍼짐, 안에서 기혈 초당 1%·진기 2배, 당가 몸은 기혈을 안 잃음, 적도 깎임), 물(장강, 굽은 물길이 지역에 깔리고 플레이어·적 0.7배, 경공 뒤 3초 수상비, 수로채 몸·수귀는 안 느려짐), 태극 바닥(무당산, 밟으면 음양 게이지 반대 속성 30초 피해 +30%, 바닥마다 60초에 한 번, 게이지 0이면 안 됨). 음양 게이지는 문파·성질 시작값에 심법 카드 한 레벨마다 ±8(balance.json `yinyang`).

### 화산·곤륜 설원·십만대산 땅의 주인(R4-02w, 2026-11-04)

낙매검선의 검혼·빙혈 설무향·혈영회주 혁련휘가 bosspatterns.json 패턴을 다 쓴다. 판정은 Core `BossPatterns`(R4-02)와 같은 셈이다(`M4BossRulesTests.웹_천하_시안이_모든_땅의_주인_모양을_Core_와_같은_셈으로_쓴다`).

|---|---|---|
| 낙매검선의 검혼 | 86초(세 판 다 잡음) | 꽃잎 나선, 매화검기 방사. 일섬은 경공으로 거의 피함 |
| 빙혈 설무향 | 64초 | 분신 몸에 닿기, 얼음 위. 얼음 가시는 거의 피함 |

같은 조건(카드·깨달음 없이 절정으로 건너뛰고 기본 기혈)이면 기존 땅의 주인도 마천패·혈허진인은 자주 쓰러진다. 그래서 위 표는 '피할 수 있는가'만 본 것이고 세기는 놀이판 값(`bossHpScale`)과 자동 조종이 서툰 탓이 섞여 있다.

### 화산·곤륜 설원·십만대산 기믹 셋(R4-11, 2026-11-04)

자리가 필요 없는 세 기믹을 gimmicks.json 그대로 붙였다. 지금 선 지역(가장 가까운 지역)에 그 기믹이 있을 때만 켠다.

- 낙석(화산, Core `FallingRocksGimmick`): 한 생 시계로 8초마다 플레이어 둘레 ±8m(축척 따름) 안 세 곳에 그림자, 1초 뒤 반경 1.8m 를 친다. 플레이어는 최대 기혈 10%(경공 중엔 안 맞음), 잡몹은 깔려 쓰러지고 정예·땅의 주인은 최대 기혈 5%.
- 눈보라(곤륜 설원, Core `WeatherGimmick`): 60초에 처음, 120초마다 20초. 화면 대각선의 0.7 밖을 흰 덮개로 가리고(카메라는 그대로), 플레이어·적 걸음 0.9배.

- 1회차는 봉인만, 2회차부터 봉인·계승(진엔딩은 의서 일곱 권·목 노인 대화가 이 시안에 없어 늘 숨음. 종장을 깬 문파 수는 `finalClears` 로 센다).

- 땅의 주인 '첫 처치'는 회차 안에서 센다(Core firstInCycle: 이 땅의 봉인석이 아직 없으면). 그래서 회귀 뒤 다시 잡으면 봉인석·윤회의 기 300 이 다시 나온다. 문파 해금은 계정에서 한 번.
- 계승: `mode:blood_demon` 을 혼에 남기고 회귀하지 않는다(혈마 모드는 출시 뒤 추가할 것이라 이 시안엔 없다).
- 모드 열림(Core `Modes.Refresh`, cheonha.json `modes`): 생을 마칠 때와 엔딩을 고를 때 조건(서장·봉인석 수·본 엔딩)을 보고 처음 열린 것을 정산 화면에 '모드 열림'으로 알린다. 열린 것은 `mode:<id>` 로 남아 회귀로 봉인석이 지워져도 닫히지 않는다. 모드 자체(일일 도전·보스 연전)는 이 시안에 없다.
- 기록은 `cheonha_meta2` 에 `cycle`·`endingPending`·`endingsSeen`·`journeyOver`·`finalClears`·`unlocks` 로 더했다(옛 기록은 1회차로 읽음).
- 콘솔: `__ch.cycleInfo()` 회차·고를 수 있는 엔딩·열린 모드, `__ch.ending('seal')` 엔딩 고르기.
- 헤드리스 크롬으로 1회차 봉인 → 봉인(회귀, 봉인석 0, 혈월 천하·보스 연전 열림) → 2회차 원각 첫 처치에 봉인석 다시 나옴(혈정 5 × 1.5 → 8) → 2회차 봉인 → 봉인·계승 중 계승(`mode:blood_demon`)까지 돌려 봄. 같은 조건 원각 기혈 5,715 → 8,573(×1.5), 적 걸음 ×1.15. 페이지 오류 없음.

### 혈마의 그림자(RM-10, 2026-11-04)

7장 '생의 끝'. 현경인데 봉인석이 일곱이 안 되면 환산 30분(`lifeEnd.shadowFromMinute`)부터 그림자 하나가 쫓아오고 환산 5분마다 한 단계씩 강해진다. 단계는 Core `LifeDirector.ShadowStep`, 세기는 `BloodShadow.Strength` 와 같은 식이다: 닿으면 30 × 1.25^(단계−1)(0.5초마다), 걸음 85 + 8 × (단계−1)(플레이어 기본 100, 3단계부터 더 빠름), 화면 위 모든 적 피해 × (1 + 0.1 × (단계−1)). 2단계부터 단계가 오를 때마다 0.5초 예고(몸 뒤 붉은 점선 원) 뒤 몸 뒤 1m × 현경 축척으로 순간이동한다(이미 더 가까우면 그대로). 그림자는 무공에 맞지 않고 밀리지도 기절하지도 않으며 돌탑을 지나간다. 봉인석이 일곱이 되면 걷힌다. 피해는 기획서 단위 그대로다(이 시안의 몸 기혈이 기획서 값이라). 몸 크기는 땅의 주인과 같다.

- 기획서와 다르게 읽은 곳: 이 시안은 현경 뒤 레벨이 몇 배로 뛰어(빨리 훑어보기면 Lv300 넘게) 다른 곳처럼 '레벨 ÷ 3'으로 환산 분을 세면 그림자가 몇 초 만에 10단계를 넘는다. 그래서 그림자만은 현경에 오른 순간의 환산 분(30분)에, 그 뒤 실제 시간 × 그 생이 현경까지 온 압축 비율을 더해 센다. 보통 속도로 9분에 현경이면 실제 1분이 환산 3.3분(한 단계가 실제 1분 반쯤), 빨리 훑어보기면 실제 30초쯤이다.
- 자동 조종은 그림자가 화면 대각선 0.35배 안에 들면 구슬·적·땅의 주인을 버리고 반대쪽으로 달아나고(장판 피하기는 그대로), 바짝 붙으면 경공을 쓴다.
- 자동 판(빨리 훑어보기, 420초, 소림·개방·남궁 8판): 그림자가 없던 판은 8판 모두 현경에서 버텼는데(현경 뒤 228~252초, 땅의 주인 1~7), 그림자를 넣으니 현경 뒤 24~89초(1~4단계)에 쓰러진다. 시안의 몸은 현경에도 기혈 100~120 이라 닿는 피해 30이 크고, 달아나는 동안 땅의 주인 패턴과 현경 덩이에 맞는다. 기획서의 '버틴 시간이 리더보드에 오른다'는 몫으로 보고 값은 그대로 두었다. (2026-11-04 RM-12 때: RM-10 이 `hitPlayer` 를 고치면서 맞은 뒤 무적 0.45초 줄이 주석 안으로 들어가 무적이 없었다. 되살린 뒤 같은 자동 판 여섯 판은 현경 뒤 21~80초(1~3단계)로 비슷했다.)

확인: 화경까지 단계 0, 현경 Lv90 에 1단계(닿으면 30, 걸음 85, 적 피해 ×1.0), 환산 35분에 2단계(37.5, 93, ×1.1)와 순간이동(예고 0.5초 뒤 몸 뒤로), 40분에 3단계(콘솔 `setTier(6)` 으로 바로 오르면 비율이 '1분 걸린 셈'이라 실제 10초마다 한 단계), 붙어 있으면 0.5초마다 37.5, 봉인석 일곱이면 사라짐. 1366x768 콘솔 에러 0.

### 숭산 기믹(RM-08, 2026-11-04)

- 기절: 적에 `stunT` 를 붙였다. 기절한 적은 걷지도, 패턴을 쓰지도, 몸으로 때리지도 않는다. 보스·정예는 패턴 시계(다음 패턴까지 남은 시간·예고)도 멈춘다(Core: 기절한 보스는 `BossPatterns.Tick` 을 안 부름). 기절한 적 머리 위에 금빛 점선 고리.
