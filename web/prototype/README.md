# 웹 프로토타입

브라우저에서 바로 해 보는 혈우강호 1장(숭산 소림)이다. Unity 판이 나오기 전에 손맛과 숫자를 먼저 확인하려고 만들었다.
캔버스 2D 한 장짜리 HTML이고, 무공·심법·절기·적·밸런스 숫자는 `unity/BloodRain/Assets/Resources/Data/*.json` 을 그대로 읽는다.

- 공개 주소: https://bloodrain-proto.pages.dev (Cloudflare Pages, 누구나 열 수 있음. main 기준)
- 미리보기 주소: https://claude-dev.bloodrain-proto.pages.dev (claude/dev 기준, 밤사이 바뀐 것)
- claude.ai 아티팩트: https://claude.ai/artifact/Aez6dR7ABbw9Z4RYK4paEg (비공개, 대화 안에서 보는 용)
- 원본은 `template.html` 하나. 빌드 결과(`site/`, `.artifact/`)는 커밋하지 않는다.
- 이펙트 시안 `web/lookdev/*.html` 도 같은 빌드로 `/lookdev/` 아래에 올라간다(예: https://bloodrain-proto.pages.dev/lookdev/samjae.html).
- 천하 시안(기획서 7·10·21장의 천하 한 장 + 환혼 + 윤회의 기): https://bloodrain-proto.pages.dev/lookdev/cheonha.html. 원본 `web/lookdev/cheonha.html`. 아래 '천하 시안' 절 참고.

## 묶기와 올리기

```
python tools/build_web_prototype.py              # site/ 에 공개용 문서 + 링크 미리보기 이미지(og.jpg)
python tools/build_web_prototype.py --artifact   # .artifact/ 에 아티팩트용 본문도
python tools/deploy_web_prototype.py             # PC에서 묶어서 정식 주소로 올리기(wrangler 로그인 필요)
python tools/deploy_web_prototype.py --branch claude/dev   # 미리보기 주소로(claude-dev 라고 쓰면 주소 뒤에 글자가 붙는다)
```

- 데이터 JSON이나 `template.html` 이 바뀌어 `main`·`claude/dev` 에 푸시되면 `.github/workflows/web-prototype.yml` 이 묶어서 올린다.
  올리기에는 저장소 비밀값 `CLOUDFLARE_API_TOKEN`·`CLOUDFLARE_ACCOUNT_ID` 가 있어야 한다(WebGL 배포와 같은 값). 없으면 묶기만 확인하고 넘어간다.
- 비밀값이 없는 동안은 PC에서 `deploy_web_prototype.py` 로 올린다. PC의 wrangler 로그인을 그대로 써서 키를 따로 만들 필요가 없다.
- 아티팩트를 다시 올릴 때는 위 아티팩트 주소에 덮어쓴다(새로 올리면 주소가 바뀐다).
- 공개용 문서는 `<!doctype>`·charset·휴대폰 viewport·링크 미리보기(og) 태그를 붙인 완전한 HTML이고, 아티팩트용은 그 뼈대가 없는 본문이다.

기획서와 데이터에 아직 없는 값이다. 해 보고 쓰기로 하면 `balance.json`·`enemies.json`·기획서로 옮긴다. `template.html` 맨 위 상수에 모여 있다.

|---|---|---|
| 맞은 뒤 무적 `HIT_IFRAMES` | 0.5초 | 없으면 강시 두세 마리에 닿기만 해도 초당 30 넘게 깎여 첫 1분을 못 넘겼다 |

## 자동 판으로 숫자 보기

페이지 콘솔에서 `__hyeolu.sim('full', 1300)` 을 부르면 자동 조종으로 한 판을 빨리 돌리고 1분마다 레벨·처치·기혈을 돌려준다. 결과의 `evo` 에 절기가 깨어난 시각·레벨·계기가 남는다. 넷째 인자로 매 걸음 불릴 함수를 줄 수 있다. 자동 조종은 사람보다 서툴다(가까운 적과 거리를 두고 돌기만 한다).
2026-10-28에 돌려 본 결과:

- 5분 Lv15 안팎으로 기획서 목표와 맞는다.
- 보통 난이도에서 자동 판은 대개 3~10분에 쓰러진다. 잘 풀린 판은 원각까지 잡는데 20분에 Lv75~100이라 목표(Lv60)를 넘는다. 강한 빌드가 적을 빨리 지우면 스폰이 `spawnFractionPerSecond` 만큼 바로 채워져 처치 수가 크게 늘기 때문이다. B-07 시뮬레이션에서 같이 볼 것.
- 데스크톱 헤드리스 크롬에서 적 220마리일 때 56fps.

절기 그릇 규칙으로 바꾼 뒤 달라진 점(기획서 목표 레벨 기준):

| | 예전(일류 + 보갑) | 그릇 규칙 |
|---|---|---|
| 첫 절기가 가장 빨리 나오는 때 | 10분 보갑(일류는 7분) | 절정 돌파, 약 11분 반 |
| 보스 전에 쓸 수 있는 절기 | 10·15분 보갑에서 둘(7장은 혈제단 보갑으로 더) | 둘(절정·초절정). 보갑이 많아도 늘지 않는다 |
| 짝 심법 | 아무 레벨 | Lv3 이상 |
| 셋째 절기 | 보스 보갑(보스를 잡은 뒤) | 화경(Lv70) 빌드만 |

자동 판(빠른 판 10번씩, 보통·편하게, 짝 심법을 먼저 올리는 조종 포함)으로는 두 규칙 차이가 잘 드러나지 않았다. 자동 조종이 대개 15분 전에 쓰러지고, 원각까지 간 판은 20분에 Lv80 안팎이라 목표(Lv60)보다 높아 그릇 셋을 채운다. 레벨이 높게 나오는 건 B-07에서 같이 본다.

## 천하 시안

`web/lookdev/cheonha.html` 은 천하 구조(기획서 5·7·10·21장)를 손으로 만져 보는 놀이판이다. 무공 고르기는 없고 검기·도는 검·먹 파동 셋이 경지에 따라 저절로 붙는다. 레벨업 카드와 원각 패턴은 T-21에서 붙인다.

원본에 데이터 자리(`/*__DATA__*/null`)가 있고, 빌드가 `cheonha.json` 전체, characters·weapons 이름, enemies.json 땅의 주인(이름·기준 체력), balance.json 의 `realms`·`xpCurve`·`training`·`stats`·`spawnTarget`·`dash`·`limits` 를 끼워 넣는다(`tools/build_web_prototype.py` 의 `cheonha_blob`). 원본 파일을 그냥 열면 빌드하라는 문구만 나온다. 데이터를 바꾸면 빌드만 다시 돌리면 된다.

### 데이터에서 그대로 읽는 것

- 문파 아홉: 이름, 태어나는 곳, 시작 무공, 대표 인물, 기혈·걸음. 처음엔 `unlock: "start"` 인 소림·개방·남궁만 열려 있고, 그 땅의 주인을 처음 쓰러뜨리면 `boss:<지역>` 문파가 열린다.
- 환생 후보 셋(21장): 열린 문파에서 겹치지 않게, 성질 0·1·2개를 20·60·20%로, `excludes` 쌍은 같이 안 붙는다. 첫 환혼은 소림·개방·남궁 고정에 성질 없음. 카드에는 태어나는 곳과 혈운 농도(빗금 굵기), 시작 무공, 기혈·걸음, 대표 인물, 성질과 효과가 나온다. 숫자키 1~3으로도 고른다.
- 몸: 문파 기혈·걸음 × (1 + 연무장 + 성질). 놀이판에 실제로 들어가는 성질 효과는 공력·기혈·신법·회복·흡기·쾌속·심득·경공 충전·호신·음식 회복(정예 구슬 회복)이다. 기연·탐욕·음양 시작은 카드에 흐리게만 보인다.
- 경지 문턱(Lv10·20·35·50·70·90)과 진기 곡선, 축척(한 단계 2.25배, 삼류 대각선 36m, 경지 안 0.35몫, 장막 2.4배, 현경부터 장막 없음), 덩이 사람 수(1·4·9·16·28·44·64, 남은 기혈만큼 줄여 그림, 처치 수는 사람 수로), 밟힘 진기 0.3, 돌파 연출 시각(세상 0.05배, 0.2~1.4초 물러남, 0.8초에 대각선 0.6배 안 쓸림).
- 혈운 농도: 가장 가까운 두 지역 섞기. 적은 생긴 자리의 농도로 기혈 × 농도, 피해 × √농도(11장 식). 화면 빗줄기는 지금 선 자리 농도만큼 굵고 많아지고, HUD 위 가운데에 지역 이름과 농도, 멀리 본 지도에는 지명 옆 빗금으로 보인다.
- 땅의 주인: 절정부터 장막 안 보스 지역이 깨어나 혈운 기둥과 화면 끝 붉은 표시가 뜬다. 장막이 넓어지면 새로 들어온 곳도 깨어난다. 지역 한가운데(대각선 0.5배)에 들어서면 1.2초 경고 뒤 싸움이고, 그동안 생성 목표가 0.4배다. 기혈 = 기준 체력 × (1 + 0.08 × 환산 분) ÷ 2.6 × 0.15. 첫 처치면 봉인석·문파 해금·윤회의 기 300, 다시 잡으면 100. 봉인석 일곱이면 봉마곡이 지도에 나타나고 현경에서 혈마가 깨어나며, 혈마를 잡으면 '봉인'으로 생이 끝난다. 그림은 모두 혈마 한 장이고, 패턴 없이 쫓아와 부딪치기만 한다.
- 윤회의 기 정산(10장): (1 + 둔재·단명 보너스) × (0.04 × Σ(구슬 값 × 주운 자리 농도) + 땅의 주인 + 처음 밟은 땅 50 + 처음 오른 경지 100). 정산 화면에 줄마다 내역이 나온다. 구슬 값은 심득을 곱하기 전 값이다.
- 연무장: 공력·기혈·신법·회복·흡기 다섯. 비용 = 기본가 × 다음 레벨 × (1 + 0.1 × 지금까지 산 총 레벨). 언제든 모두 돌려받을 수 있다.
- 생이 끝나는 길: 쓰러짐, 좌화(멈춤 화면), 봉인. 기록(기·연무장·해금·봉인석·밟은 땅·오른 경지)은 브라우저 localStorage `cheonha_meta2` 에만 남고, 저장이 막혀 있어도 판은 돈다. 제목 화면 '기록 지우기'로 처음부터.

### 놀이판에서만 쓰는 값

`cheonha.html` 맨 위 `LD` 에 모여 있고, 콘솔에서 `__ch.tune({...})` 로 바꿔 볼 수 있다. 시간은 자동 조종으로 소림에서 태어나 돌린 값이다.

| 값 | 지금 | 왜 |
|---|---|---|
| `killsPerLevel` | 14 | 덩이 하나의 진기 구슬 값 = 그 덩이가 생긴 레벨의 필요 진기 ÷ 14. 화면 위 적이 기획서보다 훨씬 적어서 구슬 하나를 크게 잡았다. 보통 속도로 이류 2분, 절정 4분 40초, 현경 9분. 구슬 값의 합이 오른 레벨의 누적 진기와 거의 같아서, 윤회의 기는 기획서 목표(농도 1에서 레벨 30 약 170, 레벨 90 약 2,000)를 따라간다 |

| `minPerLevel` | 1/3 | 환산 분 = 레벨 ÷ 3(7장 평균 도달: 레벨 35 = 11분 40초). 땅의 주인 기혈의 '경과 분'과 생성 목표에 쓴다 |
| 생성 목표 | 24 + 0.25 × balance.json 목표(환산 분) | 생성 중지 시각(19분) 뒤로는 400을 지킨다(11장). 목표 덩이 수는 최대 124 |

| `eliteEvery` | 24초 | 정예: 기혈 10배, 진기 6배, 기혈 25 회복 구슬 |

### 기획서와 다르게 읽은 곳

- 땅의 주인 '들어서면': 깨어나는 순간이나 돌파로 원이 넓어지는 순간 이미 원 안에 서 있었다면, 그때 거리의 0.6배(최소 대각선 0.12배)까지 기둥 쪽으로 다가서야 싸움이 붙는다. 소림처럼 보스 지역에서 태어나면 절정 돌파 순간 한가운데에 서 있고, 화경·현경에선 0.5배 원이 1~2km라 글자 그대로 두면 돌파하자마자 싸움이 줄줄이 붙었다.
- 처음 오른 경지 보너스는 이류~현경 여섯 번만 센다. 삼류는 태어날 때부터라 '오른' 것이 아니라고 봤다.
- 봉마곡은 봉인석 일곱 전엔 혈운 농도 섞기에서도 뺀다(지도 한가운데라 넣으면 숭산·무당 사이가 짙어진다).
- 구슬의 '그 자리 혈운 농도'는 주운 자리 값이다.
- 혈마를 쓰러뜨려도 윤회의 기 보너스는 없다(10장 표에 없음).
- 은자·혈정이 없어서 '남은 은자 절반'과 혈영 혈정 5는 빠졌다.
- 아직 없는 것: 깨달음 3택1, 레벨업 카드, 지형 기믹, 땅의 주인 패턴, 혈마의 그림자(30분 뒤), 넷째 몸·다시 고르기, 한 번 깨친 길의 짧은 연출.

### 시험 훅

콘솔에서 `__ch` 로 부른다. `start(문파 id 또는 순번, [성질 id…])`, `sim(초)`(자동 조종, 30초마다 한 줄), `setTier(n)`, `breakNow()`, `fight(지역 id)`, `warp(지역 id, 대각선 배율)`, `end('zuohwa')`, `unlockAll()`, `setStones(n)`, `addQi(n)`, `setLives(n)`, `reset()`, `draw(n)`(후보 추첨 n번의 성질 수 분포와 규칙 위반 수), `density(x, y)`, `tune({...})`.

2026-10-29 확인: `draw(5000)` 의 성질 0·1·2개가 19.5·59.9·20.6%, 안 맞는 쌍·문파 겹침 0. 콘솔 에러 0. 1366x768·360x780에서 제목·환생 카드·전투·절정 돌파·현경·보스전·정산·멈춤 화면을 찍어 보고 겹침을 고쳤다(HUD 글자 뒤 선지 깔기, 휴대폰 알림 줄을 경공 버튼 왼쪽으로, 돌파 글자와 겹치던 알림은 연출 뒤로 미룸, 지명은 겹치면 지금 땅·깨어난 땅부터).
