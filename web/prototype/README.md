# 웹 프로토타입

브라우저에서 바로 해 보는 혈우강호 1장(숭산 소림)이다. Unity 판이 나오기 전에 손맛과 숫자를 먼저 확인하려고 만들었다.
캔버스 2D 한 장짜리 HTML이고, 무공·심법·절기·적·밸런스 숫자는 `unity/BloodRain/Assets/Resources/Data/*.json` 을 그대로 읽는다.

- 공개 주소: https://bloodrain-proto.pages.dev (Cloudflare Pages, 누구나 열 수 있음. main 기준)
- 미리보기 주소: https://claude-dev.bloodrain-proto.pages.dev (claude/dev 기준, 밤사이 바뀐 것)
- claude.ai 아티팩트: https://claude.ai/artifact/Aez6dR7ABbw9Z4RYK4paEg (비공개, 대화 안에서 보는 용)
- 원본은 `template.html` 하나. 빌드 결과(`site/`, `.artifact/`)는 커밋하지 않는다.
- 이펙트 시안 `web/lookdev/*.html` 도 같은 빌드로 `/lookdev/` 아래에 올라간다(예: https://bloodrain-proto.pages.dev/lookdev/samjae.html).

## 묶기와 올리기

```
python tools/build_web_prototype.py              # site/ 에 공개용 문서 + 링크 미리보기 이미지(og.jpg)
python tools/build_web_prototype.py --artifact   # .artifact/ 에 아티팩트용 본문도
python tools/deploy_web_prototype.py             # PC에서 묶어서 정식 주소로 올리기(wrangler 로그인 필요)
```

- 데이터 JSON이나 `template.html` 이 바뀌어 `main`·`claude/dev` 에 푸시되면 `.github/workflows/web-prototype.yml` 이 묶어서 올린다.
  올리기에는 저장소 비밀값 `CLOUDFLARE_API_TOKEN`·`CLOUDFLARE_ACCOUNT_ID` 가 있어야 한다(WebGL 배포와 같은 값). 없으면 묶기만 확인하고 넘어간다.
- 비밀값이 없는 동안은 PC에서 `deploy_web_prototype.py` 로 올린다. PC의 wrangler 로그인을 그대로 써서 키를 따로 만들 필요가 없다.
- 아티팩트를 다시 올릴 때는 위 아티팩트 주소에 덮어쓴다(새로 올리면 주소가 바뀐다).
- 공개용 문서는 `<!doctype>`·charset·휴대폰 viewport·링크 미리보기(og) 태그를 붙인 완전한 HTML이고, 아티팩트용은 그 뼈대가 없는 본문이다.

## 들어 있는 것

- 진소운, 시작 무공 8종(동작은 `behavior` 별로), 심법 16종, 레벨업 3~4택(다시 고르기 2회·정진)
- 경지 돌파 이류·일류·절정·초절정·화경과 깨달음 7종(진소운이라 4개 중 고름), 돌파 보상
- 음양 태극 게이지(조화·편향·극성), 극성일 때 60초마다 기혈역류, 1초 안에 경공으로 끊으면 오의 +50
- 경공(2회 충전), 오의 일검(삼재검법 피해의 30배 직선 참격)
- 1장 시간표: 시강 → 혈강시 → 혈무사·목인나한 → 동갑시, 혈인 돌진(빈틈 있는 벽), 동갑시 포위, 금두꺼비
- 정예 셋(5·10·15분)과 보갑, Lv20 이상이면 보갑에서 절기 완성(시작 무공 8종 짝)
- 혈나한 원각(20분): 부채꼴 충격파, 십팔나한진, 범종 낙하, 30% 이하에서 빛줄기 회전
- 범종(닿으면 주변 기절), 등롱(만두·오리구이·취기부·정신부·은자)
- 빠른 판(시간 4배속, 진기 4배)과 정식 판(20분), 난이도 '편하게'(받는 피해 절반)

빠진 것: 다른 캐릭터, 해금 무공 8종, 객잔·연무장(판 밖 성장), 서장 보스 장삼, 사운드는 짧은 합성음뿐.

## 프로토타입에서만 쓰는 값

기획서와 데이터에 아직 없는 값이다. 해 보고 쓰기로 하면 `balance.json`·`enemies.json`·기획서로 옮긴다. `template.html` 맨 위 상수에 모여 있다.

| 값 | 지금 | 왜 |
|---|---|---|
| 맞은 뒤 무적 `HIT_IFRAMES` | 0.5초 | 없으면 강시 두세 마리에 닿기만 해도 초당 30 넘게 깎여 첫 1분을 못 넘겼다 |
| 강시 뛰는 비율 `HOP_DUTY` | 0.6초 중 72% | 55%면 뛰는 순간 속도가 혈강시 기준 초속 7m로 플레이어(4.6m)보다 빨라 피할 수가 없었다. 평균 속도는 데이터 그대로 |
| 처치 진기 | 시강·혈인 1, 혈강시 2, 혈무사 3, 목인나한 3, 동갑시 4, 정예 25 | `enemies.json` 에 진기 값이 없다 |
| 원각 체력 `BOSS_HP` | 정식 20,000 / 빠른 12,000 | 기획서 90,000은 초당 1,500을 가정. 프로토타입 무공으론 너무 길다 |
| 보스전 잡몹 수 `BOSS_TRASH` | 60 | 120이면 무공이 잡몹에 다 맞아 보스가 안 깎였다 |

또 하나, 삼재검법은 사거리 안에 적이 있으면 가장 가까운 적 쪽으로 벤다(기획서는 '바라보는 방향'). 도망치며 싸우는 장르라 바라보는 방향으로만 베면 뒤에서 쫓아오는 적을 거의 못 맞혔다.

## 자동 판으로 숫자 보기

페이지 콘솔에서 `__hyeolu.sim('full', 1300)` 을 부르면 자동 조종으로 한 판을 빨리 돌리고 1분마다 레벨·처치·기혈을 돌려준다. 자동 조종은 사람보다 서툴다(가까운 적과 거리를 두고 돌기만 한다).
2026-10-28에 돌려 본 결과:

- 5분 Lv15 안팎으로 기획서 목표와 맞는다.
- 보통 난이도에서 자동 판은 대개 3~10분에 쓰러진다. 잘 풀린 판은 원각까지 잡는데 20분에 Lv75~100이라 목표(Lv60)를 넘는다. 강한 빌드가 적을 빨리 지우면 스폰이 `spawnFractionPerSecond` 만큼 바로 채워져 처치 수가 크게 늘기 때문이다. B-07 시뮬레이션에서 같이 볼 것.
- 데스크톱 헤드리스 크롬에서 적 220마리일 때 56fps.
